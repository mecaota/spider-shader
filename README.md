# SpiderCocoon — 蜘蛛の糸で巻かれた繭 シェーダー (VRChat / Built-in RP)

蜘蛛モンスターが吐いた糸で対象を拘束する「繭」表現のための単体カスタムシェーダーです。
円柱状メッシュに**筒状に巻きついた平行な糸**を、テクスチャ無しで手続き的に描きます。
**Unity Built-in Render Pipeline 専用**（URP/HDRP 非対応）。同フォルダの `spider-thread` の設計思想を踏襲しています。

## このシェーダーが何をしているか（シェーダー初心者向け解説）

普通のシェーダーは「画像（テクスチャ）を貼る」ものですが、これは**ピクセルごとに数式で『ここは糸の上か、隙間か』を計算**して描きます。

1. メッシュの UV（0〜1 の平面座標）を使います。円柱メッシュなら
   - `uv.x` = 軸方向（高さ）
   - `uv.y` = 円周方向（一周すると 0→1）
   という前提です。
2. 「糸の位相」を `t = uv.x * cx + uv.y * cy` で計算します。
   - `cy = W`（巻き数）= 円周方向(uv.y)に何本の糸を並べるか。
   - `cx = tan(角度)`（軸方向のシアー）= 糸の傾き。0 なら軸に平行な糸。
   - `t` が**整数に近い場所＝糸の中心**、**半整数付近＝隙間**になります。
3. 糸の上なら色を塗り、隙間なら透明（`alpha=0`）にして背景を透かします。
4. 色は **発光的な下地**（明部は糸色そのまま・影部のみ影色まで）を基本にし、ライトの“向き”で
   影側を決めます。**ライト強度には依存しない**ので、照明が弱い／OFF でも正面が暗く沈みません。
   そこへ **各糸の断面の丸み**（`_FiberNormalStrength`）と **シーン光**（`_LightInfluence`）を混ぜ、
   仕上げに **リムライト**（`_RimFloor` で正面にも下限の発光）を足します。
5. その糸パターンを **`_LayerCount` 枚**、角度と位置をずらして **重ねて（over 合成して）** 描きます。
   レイヤー角度は **偶数/奇数で線対称**（li=0は0、li=1,2→±1段、li=3,4→±2段…）に振り、
   左右にクロスする乱雑な巻きを表現します。

## シームレス（継ぎ目が出ない）仕組み

円柱は `uv.y=0` と `uv.y=1` が同じ稜線で繋がるため、ここでパターンが途切れると縦の継ぎ目が見えます。

- `t = uv.x * cx + uv.y * cy` で、**`uv.y` に掛かる巻き数 `cy = W` が整数**である限り、
  `uv.y=0` と `uv.y=1` は「整数だけずれた同じ位相」になり、見た目が完全に連続します。
  そのため **`_WindingCount`（× `_ThreadDensity`）は内部で整数に丸めます**（`spider-thread` と同じ思想）。
- 一方、**角度は `uv.x`（軸方向）のシアー `cx = tan(角度)`** として与えます。`uv.x` は上下端が
  別の縁で巻かないため、**任意の連続角度に傾けても継ぎ目は出ません**。
  → 角度（`_FiberAngle` / `_LayerAngleStep`）は**連続値**でOK。整数スナップは不要です。

## ファイル構成

```
SpiderCocoon.shader               メイン（Properties + ForwardBase パス、レイヤー合成）
CGINC/
  SpiderCocoon_Noise.cginc        hash / value noise（太さの乱雑性）
  SpiderCocoon_Common.cginc       uniform 宣言・appdata/v2f・定数
  SpiderCocoon_Thread.cginc       糸 1 レイヤー分の評価（alpha・符号付き横断距離）
  SpiderCocoon_Lighting.cginc     各糸の法線摂動・トゥーンランプ・リムライト
```

`SpiderCocoon.shader` は `CGINC/` を相対パスで include します。フォルダ構造を保ったまま配置してください。

## 導入

1. 一式を Unity プロジェクト（VRChat World SDK3, Built-in RP）へコピー。
2. マテリアルを作成し Shader に `mecaota/SpiderCocoon` を選択。
3. **円柱メッシュ**（UV が `uv.x=軸 / uv.y=円周 0→1` でラップ）に割り当て。
   - メッシュに正しい **tangent** が含まれていること（各糸の法線曲げに使用）。Unity 標準の Cylinder はタンジェントを持ちます。

## パラメータ

### 糸のデザイン
| プロパティ | 説明 |
|---|---|
| `_ThreadColor` | 糸の色（既定 #fff）。a は全体不透明度 |
| `_ThreadThickness` | 糸の太さ（隣の糸までの間隔に対する割合） |
| `_ThreadJitter` | 糸ごとの太さの乱雑性（hash でランダムに細く／太く） |
| `_ThreadFuzz` / `_ThreadFuzzScale` | 糸長方向の太さのうねり量／細かさ |

### レイアウト（巻き）
| `_WindingCount` | 円周方向に巻く本数 W（内部で整数丸め） |
| `_ThreadDensity` | 巻き数の倍率（丸め前に乗算） |
| `_FiberAngle` | 基準の糸の角度（度・連続値。0=軸に平行、±で傾く） |

### トゥーン
| `_ToonSteps` | 陰影の段階数 |
| `_ToonSmooth` | 段差の柔らかさ |
| `_ShadowColor` | 影部の着色（明部は糸色そのまま＝発光的） |
| `_AmbientBoost` | 環境光の底上げ |
| `_LightInfluence` | シーン光の反映度（**0=完全発光**で照明に依存しない／1=光に大きく依存） |

### シルエットのリムライト
| `_RimColor` / `_RimPower` / `_RimStrength` | 輪郭の発光色／幅（大きいほど細い）／強さ |
| `_RimFloor` | リムの下限。**>0 で正面中央にも発光が乗る**（「縁は光るのに正面だけ暗い」を防ぐ） |

### 各糸ごとの陰影
| `_FiberNormalStrength` | 面法線（光ベース）と各糸の曲げ法線を混ぜる量（0=滑らかな面陰影のみ, 1=糸ごとの陰影が強い） |
| `_RimShadowColor` / `_RimShadowStrength` | 各ファイバーの縁の影色／濃さ |

### レイヤー（重ね描画）
| `_LayerCount` | レイヤー枚数（1〜8）。**最背面 index0 は常にオフセット0** |
| `_LayerAngleStep` | レイヤーごとの角度オフセット（度・連続値）。**偶数/奇数で線対称**に振る（li=1,2→±1, li=3,4→±2…） |
| `_LayerPosStepX` / `_LayerPosStepY` | レイヤーごとの位置オフセット（軸／円周）。角度と同じ線対称係数で適用 |
| `_LayerThicknessFalloff` | 奥のレイヤーほど糸を細くする量 |

### ビルボード（継ぎ目を裏へ）
| `_Billboard` | ON で円柱をローカルY軸まわりに回し、UV の継ぎ目を常にカメラの裏側へ送る |
| `_BillboardSeamOffset` | 継ぎ目位置の微調整（度）。継ぎ目が前に残る場合は 180 付近に |

### 裏面 / 視界ジャック
| `_HideBackFibers` | ON（既定）で裏面（奥の内壁）の糸を描かない。手前の隙間から**奥の暗い糸が透けるのを防ぐ** |
| `_VisionJackEnable` | ON で、**カメラが繭の内側に入ると糸が全画面に展開**して視界をジャック |
| `_VisionJackRadius` | 内側判定の半径（オブジェクト空間）。軸からの距離がこれ未満で発火。標準 Cylinder は 0.5 前後 |
| `_VisionJackHeight` | 内側判定の高さ（オブジェクト空間）。\|y\| がこれ未満で発火 |
| `_VisionJackInMirror` | ミラー内でも発火するか（既定 OFF。誤爆防止） |

> **発火はカメラ位置で判定**します（頂点の表裏ではなく、カメラがメッシュの内側にあるか）。円柱は常に半分が裏面なので、頂点単位の裏面判定だと正面から見ても誤発火します。内側判定なら外から見ている間は決して発火しません。`_VisionJackRadius`／`_VisionJackHeight` は**オブジェクト空間（Transform スケール適用前のメッシュ座標）**なので、Transform を拡大縮小しても値は据え置きでOK。カスタムメッシュで発火しない／早すぎる場合だけ調整してください。

### レンダー
| `_ZWrite` | 透過の重なり調整（既定 Off） |

## 検証チェックリスト（Unity 上で確認）

1. **糸パターン／透過**: 円柱に割り当て、`_WindingCount`・`_ThreadThickness`・`_ThreadColor` を動かし反映、隙間が透けること。
2. **シームレス**: 円柱を一周見て**縦の継ぎ目が出ない**こと。`_FiberAngle` を任意の角度に変えても保たれること。
3. **発光・陰影**: 照明を OFF にしても**正面中央が暗く沈まず糸色が出る**こと。Directional Light を回すと光の当たる面の裏側が陰ること（カメラを回しても影は動かない）。中央の発光が弱ければ `_RimFloor` を上げ、照明への依存を強めたければ `_LightInfluence` を上げる。`_FiberNormalStrength` を上げると糸ごとの陰影が強まること。
4. **トゥーン**: `_ToonSteps`・`_ToonSmooth` で段階陰影が変わること。
5. **リムライト**: `_RimColor`・`_RimPower`・`_RimStrength` で**シルエット輪郭**（糸ごとではなく面全体の縁）が発光すること。
6. **レイヤー（線対称）**: `_LayerCount` を 1→8 で枚数が増え、`_LayerAngleStep` で各層が**左右ミラーにクロス**すること。背面（オフセット0）が一番奥に見えること。
7. **ビルボード**: `_Billboard` を ON にしてカメラを周回し、**継ぎ目が常に裏側に隠れる**こと。前に残る場合は `_BillboardSeamOffset` を調整。
8. **裏面の透け防止**: `_HideBackFibers` ON で、正面から見て**手前の隙間に奥の暗い糸が透けない**こと（隙間からは背景／中の体が見える）。
9. **視界ジャック**: `_VisionJackEnable` ON で、**外から見ている間は発火せず**、カメラ（頭）を繭の内側に入れたときだけ**糸が画面全体を覆う**こと。発火が早すぎ／遅すぎる場合は `_VisionJackRadius`／`_VisionJackHeight` を調整。ミラーで誤爆しないこと（`_VisionJackInMirror` OFF）。
10. **Quest 想定**: `_LayerCount` を 2〜3 にして命令数・実機 fps を確認。

## 既知の制約 / 注意

- **角度は連続値で傾けてもシームレス**です（軸方向シアーのため）。一方 **`_WindingCount` は内部で整数丸め**されます（円周シーム維持のため）。
- **tangent 依存**: 各糸の法線曲げにメッシュの tangent を使います。tangent が無いメッシュでは陰影方向が不正確になります（必要なら UV 偏微分からの再構築に拡張可能）。
- 太さの乱雑性は巻き数 `W` 本周期で巡回します（円周シーム連続のため）。`W` が小さいと太さの種類が少なめになります。
- 透過 + `Cull Off` のため、重なり順は `_ZWrite` で調整。VRChat の半透明ソートの一般的な注意が当てはまります。
- **ビルボードは円柱状（ローカルY軸まわりに回転対称）のメッシュ前提**です。回転対称でないメッシュに掛けると見た目が崩れます。Y軸まわりの回転なのでシルエットは不変、UV（＝糸の模様の位相）だけが回って継ぎ目が裏へ移動します。継ぎ目の `fwidth` 暴走自体は aa クランプでも常時軽減しています。
- **`_HideBackFibers` は裏面（カメラに背を向けた面）を描画しません**。そのため「繭の内側に視点があり、視界ジャックが OFF」の場合は内壁が見えなくなります。内側を覆いたい場合は `_VisionJackEnable` を ON にしてください。両面の糸をそのまま見せたいときは `_HideBackFibers` を OFF に戻せます（奥の糸の透けは復活します）。
- **視界ジャック**は侵襲的な演出です。発火は**カメラが繭の内側に入ったか**で判定し（頂点の表裏ではない）、発火中はメッシュ全体をフルスクリーンへ展開します（UV が 0..1 を覆うメッシュ前提）。VR／ミラー／VRChat カメラで見え方が変わるので、既定は OFF・非ミラーで安全側にしてあります。ビルボード ON 時はカメラが内側に入りづらいので、両者は排他的な使い方になります。
