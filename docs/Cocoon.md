# 繭（Cocoon）

シェーダー名: `mecaota/Cocoon`

[← README に戻る](../README.md) ｜ 関連: [繭デカール（CocoonDecal）](CocoonDecal.md) ／ [共通機能](CommonFeatures.md) ／ [Udon ギミック](UdonGimmicks.md)

## ひとことで

**円柱メッシュに、蜘蛛の糸がぐるぐる巻きついた繭**を描くシェーダーです。糸は平たい粘液の帯として描き、帯の間には膜が張り、すき間からは中が透けて見えます。テクスチャは使いません。

- カメラ（VR では頭）が繭の中に入ると、**周りを繭の内壁が囲む「包まれ演出」（視界ジャック）**を出せます。
- 対応環境: Unity Built-in Render Pipeline。深度テクスチャは使いません。PC で動作確認しています。Quest（Android）では未検証です。
- 色・ツヤ・陰影は、蜘蛛糸のマテリアルから[継承](CommonFeatures.md#質感の継承)します。

> プレイヤーの**体の表面**に繭を張り付けたいときは、[繭デカール（CocoonDecal）](CocoonDecal.md)を使います。このページの繭は「円柱の形をした繭のオブジェクト」です。

## こんなときに使う

- 人がすっぽり入る大きさの繭を置く（中に入ると包まれる）
- 吊り下げられた繭、壁に貼り付いた繭などの背景オブジェクト

## クイックスタート

1. Hierarchy で **3D Object > Cylinder** を作ります（半径 0.5・高さ 2 の円柱）。
2. マテリアルを作って Shader を `mecaota/Cocoon` にし、円柱に入れます。
3. 中に入って包まれたいときは、インスペクタの「裏面と視界ジャック」で **視界ジャック有効** を ON にします。
4. 色やツヤは、このマテリアルでは変えられません。紫の「蜘蛛糸の質感（継承）」欄で継承元（蜘蛛糸のマテリアル）を選び、「継承元を開く」から継承元のほうで変えます。継承元がまだ無ければ「今の質感から新しい継承元を作る…」で作れます（[質感の継承](CommonFeatures.md#質感の継承)）。

### メッシュの条件

- 軸がローカル Y の円柱であること。
- UV が「`uv.x` = 軸方向（高さ）」「`uv.y` = 円周方向（一周で 0→1）」になっていること。
- 法線と接線（tangent）を持っていること。接線は帯の横方向の陰影と、接触追従の変形で使います。

既定の状態（基準の糸の角度 0）では、糸は円柱の軸と平行（縦向き）に走り、レイヤーごとに少しずつ傾いて交差します。糸が横向きに巻いて見える場合は、UV の向きが逆のメッシュです。

## しくみ（シェーダー初心者向け）

1. **糸の位相**: 各ピクセルで `t = uv.x × tan(糸の角度) + uv.y × 巻き数` を計算します。`t` が整数に近い所が糸の中心、半端な所がすき間です。
   - 巻き数（`_WindingCount`）= 円周に並ぶ糸の本数
   - 糸の角度（`_FiberAngle`）= 軸に対する傾き。0 で軸と平行
2. **レイヤー**: この模様を角度と位置を少しずつずらして何枚も重ねます。角度は偶数番目と奇数番目で左右対称に振る（1 枚目 0、2・3 枚目 ±1 段、4・5 枚目 ±2 段…）ので、左右にクロスする乱雑な巻きになります。
3. **粘液の帯**: 1 本 1 本の糸を、縁だけ丸い平たい帯として塗り、奥のレイヤーから順に重ねます。上の帯の縁は輪郭線として見え、そのすぐ外の下の帯には影が落ちます。帯の中には細い筋が数本走り、隣の帯との間にはまだらな膜が張ります。
4. **塗り**: 蜘蛛糸・蜘蛛の巣と同じ粘液の塗り（トゥーン陰影・ハイライト・輪郭線・透け）です。

### 継ぎ目が出ない理由

円柱は `uv.y = 0` と `uv.y = 1` が同じ線でつながっています。ここで模様がずれると縦の継ぎ目が見えます。

- `t` の式で `uv.y` に掛かる巻き数が**整数**なら、`uv.y = 0` と `1` の位相は整数だけずれた「同じ模様」になり、継ぎ目が出ません。そのため **巻き数（× 密度倍率）は内部で整数に丸めます**。
- 角度は `uv.x`（軸方向）に掛かるので、どんな角度に傾けても継ぎ目は出ません。角度は連続値で自由に設定できます。

## インスペクタの項目

インスペクタの並び順で載せています。紫の「蜘蛛糸の質感（継承）」欄（21 項目）は [共通機能のページ](CommonFeatures.md#継承する-21-項目) を参照してください。

| 太さの乱雑性 | `_ThreadJitter` | 0.3 | 糸ごとにランダムに細く・太くする量 |
| 幅の揺らぎ | `_ThreadFuzz` | 0.2 | 糸の長さ方向の太さのうねり |
| 揺らぎの細かさ | `_ThreadFuzzScale` | 8 | うねりの細かさ |

### 揺れアニメ（共通）

糸の模様そのものを波打たせて揺らします（メッシュは動きません）。円周方向の波の数は整数に丸めるので、揺れても継ぎ目は出ません。

| 表示名 | 内部名 | 既定値 | 説明 |
|---|---|---|---|
| 揺れアニメ有効 | `_SwayAnimEnable` | OFF | ON で揺らす |
| 揺れ幅 | `_SwayAnimAmount` | 0.012 | 揺れ幅（UV）。波の数に応じて自動で上限がかかる |
| 揺れの速さ | `_SwayAnimSpeed` | 1.5 | 揺れの速さ |
| 波の細かさ | `_SwayAnimWaves` | 2 | 波の数 |
| 端の固定幅 0で固定なし | `_SwayAnimAnchor` | 0.15 | 軸方向の両端に近い所を揺らさない幅 |

### ビルボード（固有）

| 表示名 | 内部名 | 既定値 | 説明 |
|---|---|---|---|
| ビルボード / 継ぎ目を裏へ | `_Billboard` | OFF | ON で円柱をローカル Y 軸まわりに回し、UV の継ぎ目を常にカメラの裏側へ送る |
| 継ぎ目の位置オフセット | `_BillboardSeamOffset` | 0 | 継ぎ目の位置の微調整（度）。継ぎ目が前に残るときは 180 付近に |

- Y 軸まわりに回すだけなのでシルエットは変わらず、糸の模様だけが回ります。
- 回転対称な円柱が前提です。回転対称でないメッシュに使うと見た目が崩れます。
- 回す向きはカメラの方角で決めるので、カメラが繭の中（円柱の軸の近く）にあると、少し頭を動かしただけで模様が大きく回ります。中に入る繭（視界ジャックを使う繭）では OFF のままにしてください。

### 裏面と視界ジャック（固有）

| 表示名 | 内部名 | 既定値 | 説明 |
|---|---|---|---|
| 裏面の糸を隠す | `_HideBackFibers` | ON | 裏面（奥の内壁）の糸を描かない。手前のすき間から奥の暗い糸が透けるのを防ぐ |
| 視界ジャック有効 | `_VisionJackEnable` | OFF | ON で、カメラが繭の中に入ると内壁が周りを囲む |
| 内側判定の半径 | `_VisionJackRadius` | 0.45 | 軸からの距離がこれ未満なら「中にいる」と判定（メッシュの座標で） |
| 内側判定の高さ | `_VisionJackHeight` | 0.9 | 高さ（\|y\|）がこれ未満なら「中にいる」と判定（メッシュの座標で） |
| ミラー内でも発火 | `_VisionJackInMirror` | OFF | ミラーに映る視点でも発火させるか。誤爆を防ぐため既定は OFF |
| ジャック内壁の半径倍率 | `_JackRadius` | 0.7 | 内壁の半径（内側判定の半径に掛ける） |
| ジャック内壁が閉じるまでの縦距離 | `_JackStretch` | 1 | 内壁が上下で閉じるまでの縦の長さの倍率 |

#### 視界ジャック（包まれ演出）のしくみ

- 「中にいるか」は**カメラの位置**で判定します（VR では両目の中点で判定するので、左右の目で食い違いません）。外から見ている間は決して発火しません。
- 発火すると、カメラの周りに**上下が閉じた紡錘形の内壁**を、実際の奥行き付きで描きます。頭を動かすと内壁が自然に動いて見えます。
- 壁より手前にあるもの（自分の体・同じ繭の中の他プレイヤー）は壁に隠れず見えます。壁の向こうの世界は、糸のすき間からだけ見えます。
- 内壁の模様はメッシュの UV ではなく、横向きのリングで巻いた模様です。このためレイヤー位置ステップの X / Y は、内壁では「円周 / 軸」の意味になります。
- 判定の半径・高さは**メッシュの座標**（Transform のスケールをかける前）なので、繭を拡大・縮小しても値はそのままで構いません。

> **発火範囲はメッシュの中に収めてください。** Unity は元のメッシュの範囲（バウンズ）が画面外だとオブジェクトごと描画を省きます。範囲外で発火させると、繭に背を向けた瞬間に内壁が丸ごと消えます。既定値（0.45 / 0.9）は Unity 標準の Cylinder（半径 0.5・半高 1）の内側に収まっています。

### レンダーステート（固有）

| 表示名 | 内部名 | 既定値 | 説明 |
|---|---|---|---|
| ZWrite | `_ZWrite` | Off | 繭本体の深度を書くか。半透明の重なり順の調整用 |
| ステンシル ビット | `_StencilRef` | 128 | 視界ジャックの内壁に立てる目印のビット。他のステンシルを使うシェーダーとぶつかるときだけ変える。**体に張り付く繭のマテリアルと同じ値にそろえること** |

### 接触追従の変形（固有）

触れた手足に繭の表面を追従させます。Udon の [SurfaceContactDeformer](UdonGimmicks.md#接触追従の変形surfacecontactdeformer) と組で使います。項目の説明は [Udon ギミックのページ](UdonGimmicks.md#シェーダー側の設定接触追従の変形) にまとめています（繭での `_PullRadius` の既定値は 0.3）。細かく変形させるには、細かく分割された円柱メッシュが必要です（生成ツールは同梱していません）。

### 詳細設定

Render Queue・Enable GPU Instancing・Double Sided Global Illumination（Unity 標準の項目）です。

## 描画について

3 つのパスで描きます。

| パス | 名前 | 役割 |
|---|---|---|
| 0 | `VISIONJACKDEPTH` | 視界ジャックの内壁の奥行き（深度）だけを書く。濃い所だけ |
| 1 | `VISIONJACK` | 内壁の色を塗り、ステンシル（`_StencilRef`）に目印を書く |
| 2 | `FORWARD` | 繭本体を塗る |

- パス 0・1 は、視界ジャックが発火していないときは頂点の段階で潰れて何も描きません。ふだんの負荷・描画順には影響しません。
- 描画順は `Transparent` です。
- ポイントライト・スポットライトは効きません（メインの Directional Light と環境光だけ）。影も落としません。

## 注意・制約

- **巻き数は整数に丸められます**（継ぎ目を出さないため）。角度は連続値で傾けても継ぎ目は出ません。
- 太さのランダムは巻き数の本数ごとに一周します。巻き数が少ないと太さの種類も少なくなります。
- 「裏面の糸を隠す」が ON で視界ジャックが OFF のまま中に入ると、内壁は見えません。中を覆いたいときは視界ジャックを ON にしてください。両面の糸をそのまま見せたいときは「裏面の糸を隠す」を OFF にします（奥の糸の透けは戻ります）。
- 視界ジャックは VR・ミラー・VRChat のカメラで見え方が変わるので、既定は OFF・ミラー内は発火しない設定にしています。
- **静的バッチングは自動で無効**になります（`DisableBatching`）。バッチングされるとメッシュ座標を使った判定が壊れるためです。描画回数を減らしたいときはマテリアルの **Enable GPU Instancing** を ON にしてください。ただし接触追従の変形を使う繭では OFF にします。

## 確認チェックリスト

1. 巻き数・糸の太さを動かすと反映され、すき間が透けること。
2. 円柱を一周見ても縦の継ぎ目が出ないこと。基準の糸の角度を変えても継ぎ目が出ないこと。
3. Directional Light を回すと、光の当たる面の反対側が陰ること。照明を消しても正面が真っ暗にならないこと（暗いときは継承元の「リムの下限」を上げる）。
4. レイヤー枚数を増やすと、左右にクロスする層が増えること。
5. ビルボード ON でカメラを一周させると、継ぎ目が常に裏側に隠れること。
6. 裏面の糸を隠す ON で、手前のすき間から奥の暗い糸が透けないこと。
7. 視界ジャック ON で、外から見ている間は何も起きず、頭を中に入れたときだけ内壁が周りを囲むこと。自分の体が壁に隠れないこと。ミラーで誤爆しないこと。
