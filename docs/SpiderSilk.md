# 蜘蛛糸（SpiderSilk）

シェーダー名: `mecaota/SpiderSilk`

[← README に戻る](../README.md) ｜ 関連: [共通機能（インスペクタ・質感の継承・プリセット）](CommonFeatures.md) ／ [Udon ギミック](UdonGimmicks.md)

## ひとことで

蜘蛛糸を、**Trail Renderer・Particle System の Trails モジュール・LineRenderer** が作る細長い帯（リボン）の上に描くシェーダーです。テクスチャは使わず、帯の中の糸をシェーダーの計算だけで描きます。

- 見た目は 2 種類から選べます。
  - **乾いた糸**（既定）: 細い糸が数本、帯に沿って走ります。
  - **粘液モード**: 太い粘液の束が蛇行し、束の間に穴の空いた膜が張ります（アニメの「いとをはく」のような見た目）。
- このシェーダーの「質感」（粘液の色・ツヤ・トゥーン・リム）は、蜘蛛の巣・繭・繭デカール・蜘蛛の巣ドレープに**継承**されます。くわしくは [質感の継承](CommonFeatures.md#質感の継承) を参照してください。
- 対応環境: Unity Built-in Render Pipeline。PC で動作確認しています。Quest（Android）では未検証です。

## こんなときに使う

- 蜘蛛が糸を飛ばす・吐きかける演出（パーティクルのトレイル）
- 吊り糸や、体と巣をつなぐ粘着糸（LineRenderer）
- 糸いぼから垂れる、重力でたゆむ糸

## クイックスタート（Trail Renderer で試す）

1. Project ウィンドウで右クリック → **Create > Material** でマテリアルを作り、Shader を `mecaota/SpiderSilk` にします。
2. インスペクタ先頭の緑色の「プリセット」欄で **「粘液の吐き糸」** を押します（乾いた糸にしたいときは「乾いた糸（従来）」）。
3. 動くオブジェクトに **Trail Renderer** を付け、Materials に 2 のマテリアルを入れます。
4. Trail Renderer の **Texture Mode を Tile** にします（粘液の玉や穴の間隔が、トレイルの長さに関係なく一定になります）。
5. Width（帯の幅）を 0.05〜0.2 m くらいにして、再生しながらオブジェクトを動かします。

> 「粘液の吐き糸」プリセットには重力のたゆみ（後述）が入っていますが、たゆみはパーティクル側の追加設定が無いと効きません。設定しなくても糸は普通に表示されます。

## しくみ（シェーダー初心者向け）

ふつうのシェーダーは画像（テクスチャ）を貼りますが、このシェーダーは**ピクセルごとに「ここは糸の上か、すき間か」を計算**して塗ります。Web でいえば、画像を `<img>` で貼るのではなく、Canvas に数式で毎フレーム描いているイメージです。

1. Unity のトレイルは、自動で帯のメッシュを作り、UV（帯の上の座標）を付けてくれます。
   - `uv.x` = 軌跡に沿った方向（吐き出し口が 0）
   - `uv.y` = 帯の幅方向（0〜1）
2. **乾いた糸モード**では、「糸の位相」`t = uv.x × tan(糸の角度) + uv.y × 本数` を計算し、`t` が整数に近い所を糸、半端な所をすき間として塗ります。これを角度や位置をずらして何枚か重ねます（レイヤー）。
3. **粘液モード**では、帯の中に 1〜4 本の太い束を置き、各ピクセルから「一番近い粘液の輪郭までの距離（中なら負）」を計算して、負の所だけ塗ります（距離場、SDF とも呼びます）。SVG のパスをピクセル単位で判定しているようなものです。
   - 2 つの形の距離を「小さい方」ではなく「なめらかな小さい方」（smooth-min）で合成すると、近づいた所が水かき状につながります。これが粘液らしい“ねばっ”とした合流の正体です。
   - 束の間には膜を張り、ランダムな丸い穴を空けます。穴が広がると、残った部分が不揃いな糸と粘着だまりになります。
   - 輪郭からの深さを「丸い棒の断面」とみなして、トゥーン陰影・白いハイライトの筋・輪郭線を付けます。中心ほど少し透けます（ゼリーのような見え方）。
4. **頂点カラーを掛け算**するので、Trail の Color や Color over Lifetime で「尻尾に向かって消える」などの演出をパーティクル側で決められます。粘液モードでは頂点の不透明度（アルファ）を「引き伸ばされた量」とみなし、尻尾ほど束を細くします。
5. トレイルには法線（面の向き）がないので、陰影は「カメラの方を向いた面」とみなして計算しています。

## 使い方別の設定

用途によって Texture Mode の正解が逆になるので注意してください。

| 使い方 | Texture Mode | 必要な設定 |
|---|---|---|
| Trail Renderer / Particle の Trails（乾いた糸） | Stretch 推奨（Tile でも可） | 特になし |
| Trail Renderer / Particle の Trails（粘液モード） | **Tile** 推奨 | Particle の場合は下の「Custom Vertex Streams」を推奨 |
| パーティクルの糸を重力でたゆませる | **Tile** 必須 | 下の「重力のたゆみ（パーティクル）」 |
| LineRenderer を SurfaceContactDeformer の「粘液の糸」に使う | **Stretch** 必須 | Use World Space を ON。値はスクリプトが設定（[Udon ギミック](UdonGimmicks.md#粘液の糸thread-by-slot)） |
| LineRenderer 単体の細い吊り糸 | Tile | プリセット「細い粘液糸（1本・粘着玉）」 |

### Custom Vertex Streams（Particle System の Trails）

Renderer モジュールの **Custom Vertex Streams** を ON にし、Trail 用のストリームを `Position, Color, UV, StableRandom.xyzw` の順に指定します。粒ごとの乱数が `TEXCOORD0.zw` に入り、連射したトレイルが全部同じ模様に見えるのを防ぎます（指定しなくても動作はします）。

Trails モジュール用のマテリアルは、Renderer モジュールの **Trail Material** 欄に入れます。

## 重力のたゆみ

糸の頂点をワールドの真下（-Y）へたわませる表現です。物理シミュレーションではなく見た目だけの変形で、両端（吐き出し口と先端）は固定されます。たわみは元の経路より上には出ません。

たわませるには「その頂点が糸の何割の位置か」が必要です。次のどちらかが設定されたマテリアルでだけ効きます。

| 方式 | 設定方法 | 使う場面 |
|---|---|---|
| 頂点色の青を位置として使う | プリセット **「粘液の吐き糸」** か **「乾いた糸＋重力のたゆみ」** を適用する（インスペクタには出ない隠し設定 `_GravityTrailColor` が 1 になる） | パーティクルの糸 |
| UV を位置として使う | SurfaceContactDeformer が実行中に自動設定（`_GravityUseUV`・`_GravityLineLength`） | LineRenderer の粘液の糸 |

### 重力のたゆみ（パーティクル）

1. Trails モジュールの Texture Mode を **Tile** にします。
2. 上の Custom Vertex Streams を設定します。
3. **Color over Trail** の青チャンネルを、吐き出し口 0 → 先端 1 のグラデーションにします。描画時、青は 1 に戻されるので色味は変わりません（Linear 色空間の変換も戻します）。
4. 開始色や Color over Lifetime の**青は 1 のまま**にしてください。赤・緑・不透明度は自由に使えます。

補足:

- Unity 2022.3 では、Tile のとき Percentage Along Trail が 0〜1 にならないため、この「青チャンネル」方式を使っています。
- このモードのたわみは、推定したトレイルの長さの 8% までに抑えられます。
- 生成直後で頂点が 2 つしかない糸は、途中の頂点ができるまで曲がりません。Min Vertex Distance を小さめ（例: 0.08 m）にすると早く曲がり始めます。
- たゆみが有効な間は、下の「トレイルの揺れ」（帯の幅方向の揺れ）は止まります。

## 描画順とステンシル

- 描画順は `Transparent-10`（2990）です。蜘蛛の巣・繭（`Transparent`）より**先**に描きます。
- 2 つのパスで描きます。
  - Pass 0 `DEPTHSOLID`: 色は塗らず、不透明度 0.5 以上の芯だけ深度とステンシル（`_SilkStencilBit`）を書きます。
  - Pass 1 `FORWARD`: 深度は書かずに全体を塗ります。
- 先に描く理由: 巣や繭は、半透明でも前後関係を保つために濃い所だけ深度を書きます。糸を後から描くと、その深度に負けて「巣の向こうに透けて見えるはずの糸」が消えてしまいます。先に描けば、奥の糸の上に巣や繭が半透明で重なるので、糸は必ず透けて見えます。
- ステンシルは、[繭デカール（CocoonDecal）](CocoonDecal.md)が「体の手前を通る糸の上に繭を塗らない」ための目印です。`_SilkStencilBit` を変えたら、体に張り付く繭のマテリアル（インスペクタでは「繭デカール」）の `_GlueStencilReadMask`（既定 208 = 視界ジャック用の 128 ＋ 糸の 64 ＋ 蜘蛛の体の 16）も合わせてください。

## 注意・制約

- 帯はカメラの方を向く前提（トレイルの標準の向き）で陰影を付けています。Alignment を変えても描画はされますが、陰影が不自然になることがあります。
- 半透明・両面描画（Cull Off）なので、糸どうしが激しく交差すると前後関係が不正確になることがあります（半透明の一般的な制約）。
- ポイントライト・スポットライトは効きません（メインの Directional Light と環境光だけを使います）。影も落としません。
- Pass 0 は Pass 1 と同じ塗りの計算をもう一度行うため、そのぶん負荷がかかります。

## 確認チェックリスト

1. 乾いた糸: `_WindingCount`・`_ThreadThickness` を動かすと本数・太さが変わり、すき間が透けること。
2. 粘液モード: ON にすると太い束と膜に変わること。Texture Mode を Tile にすると、トレイルが伸びても玉や穴の間隔が変わらないこと。
3. 揺れ: `_SwayAmount` を上げると糸がたなびき、吐き出し口では揺れないこと。
4. 重力: パーティクルの設定（Tile・Vertex Streams・Color over Trail の青）をしたうえで `_GravitySag` を上げると、両端を残して中央が下がること。
5. 継承: このマテリアルの質感（紫の項目）を変えると、これを継承している巣・繭のマテリアルにすぐ反映されること。
