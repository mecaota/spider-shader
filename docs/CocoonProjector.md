# 繭プロジェクター（CocoonProjector）

シェーダー名: `mecaota/CocoonProjector`

> **試験実装です。** 実機の VRChat（VR の両目・ミラー・多人数）での確認は済んでいません。駆動する Udon は [`SpiderCocoonProjectorMaskDriver`](#駆動スクリプトspidercocoonprojectormaskdriver) として同梱しています。

## ひとことで

[繭デカール](CocoonDecal.md)を、**捕まった人のアバターにだけ**描くための目印を付けるシェーダーです。色は一切塗りません。

- 体に張り付く繭は「深度テクスチャに写っている、円筒の中の面」ならどこにでも繭を描くので、円筒に入った床・木・壁や、隣に立つ別の人にも繭が乗ることがあります。
- このシェーダーを Projector で使うと、捕まった人のアバターの見えている画素にだけ、ステンシルの目印（ビット 32）が立ちます。繭のマテリアルを「目印のある画素にだけ描く」設定にすると、床・壁・隣の人には繭が出なくなります。
- 対応環境: **PC 専用**（体に張り付く繭と同じ）。Unity Built-in Render Pipeline。

## しくみ（シェーダー初心者向け）

- **ステンシル**は、画面の画素ごとに持てる 8 ビットの小さなメモです。このパッケージでは 128 ＝ 視界ジャックの内壁、64 ＝ 蜘蛛糸の芯、**32 ＝ 受け手（繭を描いてよいアバター）**、16 ＝ 蜘蛛の体（ワールド側のシェーダーが立てる）に使います。
- Unity の **Projector** は「投影範囲に入ったレンダラーを、Projector のマテリアルでもう一度描く」部品です。Projector の Ignore Layers で `Player`・`PlayerLocal`・`MirrorReflection` 以外をすべて無視すると、アバターのメッシュだけがこのシェーダーで描き直されます。
- このシェーダーは、描き直された相手が捕まった本人かどうかを、相手のメッシュの原点（足元か腰）と、スクリプトが渡す本人の骨の位置で判定します。本人でなければ何も描きません。本人なら、見えている画素（手前の柱・壁・他人には負ける）に目印のビットを立てます。
- 体に張り付く繭は輪郭の少し外（糸の厚みの分）にも糸を盛るので、このシェーダーも頂点を同じ幅だけ外へ膨らませます。
- 膨らませた分のすき間に入った物（触れている他の人の手など）には目印を立てません（[手前の物で切る](#手前の物で切る)）。
- 目印はいつも体全体に立てます（繭を付ける部位を選ぶ機能は外しました。[部位の選択を外したこと](#部位の選択を外したこと)）。

## 手前の物で切る

捕まった人に触れている他の人の手や、すぐ前を通る物には繭を出しません（既定 ON）。

- **なぜ要るか**: 目印は、体の面を糸の厚み（既定 6 cm）だけカメラ側へ膨らませて立てます。すると、体の面と膨らませた面のすき間に入った物（触れている他の人の手など）の画素にも目印が立ち、そこに繭が出ます。
- **しくみ**: 画素ごとに、カメラから見えている一番手前の面の深さ（深度テクスチャ。繭のマテリアルが体の表面を探すのに使っているものと同じ）を読みます。見えている面が「膨らませる前の体の面」より「手前とみなす距離」以上手前なら、手前に別の物があるので目印を立てません。体の面そのもの（深さがほぼ同じ）と、輪郭の外の背景（深さが奥）には今までどおり立ちます。ウェブで例えると、画素ごとに重なり順（z-index）を比べて、上に別の要素が重なっている所だけ塗らないようなものです。
- 捕まった人自身の手は体の一部なので、腰に置いても手そのものに目印が立ちます（手にも繭が出ます）。
- 判定は Projector ごとに閉じているので、何人分もの Projector を重ねても、互いの目印を消し合いません。
- 「手前とみなす距離」（既定 0.01 m）より体に近い所（体に触れている指の側面など）は切れません。手の厚み（2〜3 cm）より大きくすると、手の甲にも繭が出るようになります。小さすぎると深さの誤差で体の繭に小さな穴が開くことがあります。
- 手前の物が体の真横にあって、深さが体とほとんど同じときは、その縁に今までどおり糸がかかります（奥にある物に糸の厚みがかぶる見え方は残します）。
- OFF にすると、0.13.1 までと同じ見え方に戻ります。

## セットアップ

1. **マテリアル**: `mecaota/CocoonProjector` のマテリアルを、**Projector 1 つにつき 1 つ**作ります（共有すると全員が同じ人として扱われます）。「輪郭の外への膨張」は繭のマテリアルの「糸の厚み」（`_GlueThickness`）と同じ値にします。
2. **Projector**: 空の GameObject に Projector を付けます。
   - Orthographic を ON。Orthographic Size は 1.2 前後（両腕を広げた幅の半分より少し大きく）。Near Clip Plane は 0.1、Far Clip Plane は 3（頭の上 0.5 m から足元まで届く長さ）。
   - 向きと位置は駆動スクリプトが毎フレーム決めます（捕まった人の頭の上から真下へ）。
   - Ignore Layers ＝ `Player`・`PlayerLocal`・`MirrorReflection` **以外すべて**。
   - GameObject 自身のレイヤーは Default（ミラーに映るレイヤー。ミラーの中でも目印が立ちます）。
   - Material ＝ 1 のマテリアル。
3. **繭のマテリアル**: 体に張り付く繭のマテリアルを `_GlueStencilRef` 32 / `_GlueStencilReadMask` 240 にします（[レンダーステート](CocoonDecal.md#レンダーステート固有)）。
4. **駆動スクリプト**: 別の GameObject に [`SpiderCocoonProjectorMaskDriver`](#駆動スクリプトspidercocoonprojectormaskdriver) を付け、Projector Transform に 2 の GameObject、Mask Material に 1 のマテリアルを入れます。捕まった人が決まったら、捕獲を扱うスクリプトから `SetOwner(playerId)` を呼びます。

## 駆動スクリプト（SpiderCocoonProjectorMaskDriver）

`Runtime/CocoonProjectorMask/SpiderCocoonProjectorMaskDriver.cs`。毎フレーム、マスクのマテリアルに `_OwnerRoot`（足元）・`_OwnerHips`（腰）・`_OwnerPt0`〜`_OwnerPt5`（頭・胸・左手・右手・左足・右足）を `Material.SetVector` で渡し（xyz ＝ 位置、w ＝ 許容半径 m）、Projector を捕まった人の頭の上へ動かして真下へ向けます。誰も捕まっていない間は、Projector の GameObject を無効にして、描き直しの負荷をなくします。

| 設定項目 | 既定値 | 説明 |
|---|---|---|
| Projector Transform | （必須） | Projector を付けた GameObject。誰もいない間は GameObject ごと無効にするので、**このスクリプトとは別の GameObject** にする |
| Mask Material | （必須） | Projector に入れたマスクのマテリアル |
| Follow Local Player | OFF | ON で、`SetOwner` を呼ばなくても自分を対象にする（動作確認用。デバッグ表示と組み合わせると、自分の体に緑が乗るのを確かめられる） |
| Height Above Head | 0.5 | 頭からどれだけ上に Projector を置くか m |
| Root Radius | 0.35 | アバターのメッシュの原点が足元からこの距離以内なら本人とみなす |
| Hips Radius | 0.35 | 原点が腰の骨からこの距離以内なら本人とみなす |
| Attachment Radius | 0.5 | 手に持つ物・帽子・靴・衣装の付属品（しっぽ・羽など）など骨の下の物の原点が、頭・胸・両手・両足からこの距離以内なら本人の物とみなす。0 で使わない。広げすぎると、すぐ隣に立つ人の物まで本人の物とみなす（0.12.0 までの既定は 0.25。置き済みのスクリプトは値が残るので、インスペクタで変える） |
| Cocoon Renderer | 空 | 繭デカールの箱の Renderer（任意）。入れると、[太さをそろえる](#太さをそろえる)ための筒を骨から毎フレーム計算して、この Renderer に渡す |

| メソッド | 内容 |
|---|---|
| `SetOwner(int playerId)` | この人のアバターにだけ繭を描かせる |
| `ClearOwner()` | やめる（Projector を無効にする） |
| `GetOwnerId()` | 今の対象の playerId（いなければ 0） |

- 対象の人が退室すると自動で `ClearOwner` します。
- このスクリプトは同期しません。全員に同じ見え方をさせたいときは、捕獲を同期しているスクリプトから、全員のクライアントで `SetOwner` を呼びます。
- 同時に何人もの繭を描き分けるときは、人数分の「Projector ＋ マスクのマテリアル ＋ 駆動スクリプト」を用意します。

## 太さをそろえる

体に沿って巻いた繭はミイラのように見えます。繭デカールのマテリアルの「[太さをそろえる](CocoonDecal.md#太さをそろえる固有)」（`_EvenGirth`）を上げると、体の一番太い所に合わせた、太さのそろった繭に近づきます（0 ＝ 今までどおり、1 ＝ 太さのそろった繭）。値は繭デカールのマテリアルにあるので、同じマテリアルを使う繭はまとめて変わります。

- 駆動スクリプトの **Cocoon Renderer** に、同じ人を包む繭デカールの箱（の Renderer）を入れてください。駆動スクリプトが毎フレーム、捕まった人の骨から「繭をそろえる筒」を計算して、その箱に渡します（MaterialPropertyBlock の `_EvenGirthA` / `_EvenGirthB`）。入れないと筒は描かれません（「太さをそろえる」を上げても 0 と同じ）。誰も捕まっていないときも描かれません。
- **筒の作り方**: 体を、骨と骨を結ぶ円柱（大人の体の目安の太さを、その人の大きさで伸び縮みさせたもの）の集まりと考えます。体の軸（腰 → 頭）に沿って一番下の骨から一番上の骨まで、軸から一番遠くまで張り出した所（骨 ＋ 円柱の太さ）までを含む筒にします。腕を下ろして立っていれば、一番太い所は腕の外側です。
- 筒の上端は頭のてっぺん、下端は足の裏です（骨の位置で止め、太さは足しません）。
- 衣装のふくらみ（スカート・大きな髪など）は骨からは分かりません。体の繭が筒からはみ出すときは、繭デカールの「そろえた繭の太さの足し引き」を上げてください。はみ出した所は、今までどおり体に沿って巻かれます（穴は開きません）。
- 腕を横に広げると、一番太い所が広がって筒も太くなります。
- 筒は繭デカールの箱の外には描かれません。箱は筒が入る大きさにしてください。駆動スクリプトは最後に渡した筒を `girthBottom`・`girthTop`（ワールドの下端・上端）と `girthRadius`（体の一番太い所までの半径。0 なら渡していない）に残すので、箱を動かすスクリプトはこれに「足し引き ＋ 糸の厚み ＋ ほつれ幅」を足した大きさまで箱を広げます。
- 繭プロジェクターの目印は今までどおり体にだけ立ちます。筒は繭デカールが式で形を求め、手前の物と比べて描くので、目印の無い体の輪郭の外（脚の間の背景など）にも描かれ、床・壁・隣の人には糸がにじみません。
- 筒の中に入った物（腰に置いた手、抱きついている人の腕など）は筒に隠れます。筒の手前にある物は隠れません。

## インスペクタの項目

Unity 標準のインスペクタで表示されます（このパッケージの専用インスペクタ・プリセット・質感の継承には対応していません）。

| 表示名 | 内部名 | 既定値 | 説明 |
|---|---|---|---|
| 受け手ビット | `_StencilReceiverBit` | 32 | 立てるビット。繭のマテリアルの `_GlueStencilRef` と同じ値にする（64・128 は使えない） |
| 輪郭の外への膨張 m | `_Inflate` | 0.06 | 繭のマテリアルの「糸の厚み」と同じ値にする |
| 手前の物で切る | `_OccluderCut` | ON | 体の面より手前に見えている物（腰に置いた手など）には目印を立てない（[手前の物で切る](#手前の物で切る)）。OFF で 0.13.1 までと同じ |
| 手前とみなす距離 m | `_OccluderTolerance` | 0.01 | 見えている面が体の面よりこの距離以上手前なら「手前の物」とみなす。手の厚みより小さくする |
| 対象 | `_OwnerMode` | 所有者のみ | 0 ＝ 投影範囲の全員、1 ＝ 所有者（捕まった人）だけ |
| 所有者のルート / 腰 | `_OwnerRoot` / `_OwnerHips` | (0,-9999,0,0) | xyz ＝ 位置、w ＝ 許容半径 m。スクリプトが毎フレーム設定 |
| 所有者の頭・胸・両手・両足 | `_OwnerPt0`〜`_OwnerPt5` | (0,-9999,0,0) | 手に持つ物・帽子・靴など骨の下の物の原点がここに近ければ、本人の物として受け入れる。w ≤ 0 で無効 |
| 視錐台の外を切る | `_FrustumClip` | OFF | 全員モードで範囲を絞るときだけ ON |
| デバッグ表示 | `_DebugView` | Off | On で目印が立つ範囲を緑で塗る（確認用） |

## 描画について

- 描画順は `Transparent-100`（2900）です。アバター（不透明 2000、カットアウト 2450、lilToon の半透明 2460 など）の後、蜘蛛糸（2990）と繭（3000）の前に描きます。
- Frame Debugger で、アバター → このマスク → 蜘蛛糸の `DEPTHSOLID` → 体に張り付く繭のパス 2、の順に並んでいることを確かめてください。

## 注意・制約

- `IgnoreProjector` が ON のアバターのマテリアル（Standard の Fade / Transparent など）には目印が立たず、その部位には繭が出ません。
- マスク（2900）より後でステンシルを書き換える（Replace する）アバターの部位では目印が消え、その部位には繭が出ません。
- Default レイヤーを映さないミラー（低画質のミラーなど）の中では繭が出ません。
- VR のシングルパスインスタンシングでは、Projector が片目にしか描かれない Unity の既知の問題があります。
- 実機の VRChat（VR の両目・ミラー・多人数）での確認は済んでいません。
- 「手前の物で切る」は深度テクスチャを読みます。深度テクスチャに写らない物（影を落とさない材質や半透明の材質の手など）は「手前の物」とみなされず、今までどおり繭が出ます。深度テクスチャは繭のマテリアルにも必須なので（影付きのリアルタイム Directional Light）、新しく用意する物はありません。
- 正射影（Orthographic）のカメラでは「手前の物で切る」は働きません（今までどおり目印を立てます）。
- 繭そのものを描くのは繭デカールです。手を広げたり上げたりして手が繭デカールの箱（円筒）の外へ出ると、目印があってもそこには繭が出ません。箱を体に合わせて動かすスクリプトでは、手・肘の骨も箱の大きさに含めてください。

## 部位の選択を外したこと

0.13.0〜0.14.0 にあった「繭を付ける部位を選ぶ」機能（Humanoid のボーン名の 17 部位、駆動スクリプトの Bones）は外しました。手足は大きく動くので、骨から作る部位の範囲から外れて、繭が切れたりはみ出したりしたためです。今は捕まった人の体全体に目印を立てます。

- 駆動スクリプトの `SetBones`・`SetBone`・`SetWholeBody`・`SetNoBones`・`HasBone`・`GetBones` を呼んでいるスクリプトは、その行を消してください（残っているとコンパイルエラーになります）。`SetWholeBody` を呼んでいた所は、消せば同じ見え方です。
- シーンの駆動スクリプトの Bones に入れていた値は使われず、全身に繭が付きます。
- マスクのマテリアルに残っている「部位」「骨」の値は使われません。そのままで構いません。
