# 繭デカール（CocoonDecal）

シェーダー名: `mecaota/CocoonDecal`

[← README に戻る](../README.md) ｜ 関連: [繭（Cocoon）](Cocoon.md) ／ [共通機能](CommonFeatures.md) ／ [Udon ギミック](UdonGimmicks.md)

## ひとことで

プレイヤーの体を囲む**箱（Cube）**に貼ると、その中にある**アバターの体の表面にぴったり沿って繭の糸が巻きつく**シェーダーです。他の人・デスクトップ・VRChat のカメラから見ると、捕まった人の体のシルエットに糸が張り付いて見えます。

- 巻かれている本人がカメラごと中に入ると、[繭本体](Cocoon.md)と同じ**視界ジャック（包まれ演出）**が出ます。
- 腕と胴など、くっついた複数の繭を**1 つの繭としてまとめて描く**こともできます（[CocoonGroupLinker](UdonGimmicks.md#繭のまとめ描きcocoongrouplinker)）。
- 対応環境: **PC 専用**（Quest は非対応）。Unity Built-in Render Pipeline。
- インスペクタの表示や一部の説明では、このシェーダーを「繭デカール」と呼んでいます。

> **必須**: ワールドに**影付きのリアルタイム Directional Light** が必要です。無いと体に張り付く繭は一切描かれません（視界ジャックだけは出ます）。

## こんなときに使う

- 罠にかかったプレイヤーの胴・手足を糸で巻く
- 両手首・両足をまとめて縛られたように見せる
- 糸が少しずつ巻かれて繭になっていく演出（巻きアニメ）

## クイックスタート

1. Hierarchy で **3D Object > Cube** を作ります。コライダーは不要なので外して構いません。
2. マテリアルを作って Shader を `mecaota/CocoonDecal` にし、Cube に入れます。
3. ワールドに Directional Light を置き、**Shadow Type を Soft Shadows か Hard Shadows**（Realtime）にします。
4. Cube を巻きたい部位を包むように置きます（向きとスケールは下の表）。
5. Play して、別のカメラ（Scene ビューやデスクトップ視点）から見て、体の表面に糸が沿っていれば成功です。一人称の自分の視点では、自分の体には張り付きません（[注意・制約](#注意制約)）。

| Cube の設定 | 合わせ方 |
|---|---|
| ローカル Y（上方向） | 体の軸（腰 → 頭、肩 → 手首など）に向ける |
| Scale Y | 巻く部分の長さ |
| Scale X・Z | 巻く部分の太さ（直径）。X と Z はほぼ同じにする |
| ローカル −X の側 | 体の背中側に向けると、巻きの継ぎ目が背中に隠れる |

- 動くプレイヤーに追従させるには、Cube をボーンに合わせて毎フレーム動かす仕組みが必要です。同梱の [SurfaceContactDeformer](UdonGimmicks.md#接触追従の変形surfacecontactdeformer) の「Wrap By Bone」で、捕まえたボーンに追従させられます。自前の追従スクリプトでも構いません。
- 親オブジェクトにはスケール (1,1,1)（少なくとも縦横比の同じスケール）を使ってください。縦横比の違うスケールの親の下で回転させると、円筒の形がずれることがあります。

## しくみ（シェーダー初心者向け）

1. カメラは描画のついでに、画面の各ピクセルまでの距離（**深度テクスチャ**）を作っています。影付きのライトがあると、Unity はこの深度を必ず作ります。
2. このシェーダーは Cube の表面を描くとき、各ピクセルで深度を読み、「その向こうにある面（＝アバターの体）」の 3D 位置を逆算します。
3. その位置が Cube に内接する円筒の中にあれば、円筒座標（高さと角度）で繭の帯を描きます。体の表面の位置そのものに塗るので、シルエットにぴったり沿います。
4. 繭の軸・太さは Cube の位置・向き・スケールから決めます。スクリプトからマテリアルに値を渡す必要はありません。

Web でいえば、CSS の `backdrop-filter` のように「後ろにある物を読み取って、その上に描く」処理です。

### 描く優先順位

ピクセルごとに、上から順に当てはまったものを描きます。

1. **体表に張り付ける（glue）**: 深度から戻した表面が円筒（＋投影の許容距離）の中にあれば、体の表面に糸を塗ります。腕や肩など、円筒から少しはみ出した部位も許容距離で拾います。
2. **糸の厚み**: 体の輪郭のすぐ外側も、厚みの分だけ糸を盛ります。体の前面と輪郭が 1 つの続いた殻のように見えます。両足の間隔が厚みの 2 倍以内なら左右の殻がつながり、まとめて巻かれているように見えます。床のような続いた面は覆いません。
3. **床・天井のテクスチャ**: 床・天井と判定したピクセルには、糸ではなく指定したテクスチャ（蜘蛛の巣など）を貼ります。未設定なら何も描きません。
4. どれにも当てはまらないピクセルには何も描きません。

### ミラー

ミラー専用のパスが、鏡の中でも通常の視点と同じ体表の繭を描きます（設定不要）。

- ミラーのカメラは鏡面に沿った特殊な投影なので、専用の計算で深度から位置を戻しています。
- 鏡の中の柱・壁など、手前の物には正しく隠れます。
- 鏡の中では「糸の厚み」と「床・天井のテクスチャ」は使いません。

### 視界ジャック（包まれ演出）

カメラが円筒（「円筒半径」「円筒高さ」で決まる殻）の中に入ると、カメラの周りに繭の内壁を実際の奥行き付きで描きます。仕組みは [繭本体の視界ジャック](Cocoon.md#視界ジャック包まれ演出のしくみ) と同じです。

- 壁より手前の物（自分の体・同じ繭の中の他プレイヤー）は隠れません。壁の向こうは糸のすき間からだけ見えます。
- 体表の繭は発火中も描かれ続けるので、巻かれた体ごと繭の中にいる見え方になります。
- 内壁の半径を実際の円筒より小さくしても、カメラが内壁の外に出る位置では中心を自動で内側へ寄せるので破綻しません。

## インスペクタの項目

インスペクタの並び順で載せています。紫の「蜘蛛糸の質感（継承）」欄（21 項目）は [共通機能のページ](CommonFeatures.md#継承する-21-項目) を参照してください。

### 糸のデザイン・巻きのレイアウト（共通）

[繭本体](Cocoon.md#糸のデザイン共通)と同じ項目・同じ既定値です（糸の太さ 0.35、巻き数 24 など）。ただし、このデカールは横向きのリングで巻くので、次の違いがあります。

- 糸の角度は「1 周で整数本ぶん進む閉じた螺旋」に自動でそろえます（継ぎ目で糸がずれないため）。見た目の傾きはほぼ設定どおりです。
- 継ぎ目は Cube のローカル −X の側に来ます。

### レイヤー（共通）

| 表示名 | 内部名 | 既定値 | 説明 |
|---|---|---|---|
| レイヤー枚数 | `_LayerCount` | 3 | 重ねる枚数（1〜8） |
| レイヤー角度ステップ | `_LayerAngleStep` | 8 | 1 段ごとに傾ける角度（度） |
| レイヤー位置ステップ X 円周 | `_LayerPosStepX` | 0.02 | 1 段ごとに円周方向へずらす量 |
| レイヤー位置ステップ Y 軸 | `_LayerPosStepY` | 0 | 1 段ごとに軸方向へずらす量 |
| 奥レイヤーの減衰 | `_LayerThicknessFalloff` | 0 | 奥のレイヤーほど糸を細くする量 |

> 繭本体とは X / Y の意味（円周と軸）と既定値が入れ替わっています。

### 蜘蛛の巣ドレープ風の表面（固有）

体表の繭・まとめ繭・視界ジャックの内壁の模様を、[蜘蛛の巣ドレープ](SpiderWebDrape.md)と同じ「平行に並んだ粘液の束と、穴の空いた膜」にします。

| 表示名 | 内部名 | 既定値 | 説明 |
|---|---|---|---|
| 表面の模様 0=繭の帯 1=蜘蛛の巣ドレープ | `_SurfaceStyle` | 0 | 0 は従来の斜めに交差した繭の帯。1 で蜘蛛の巣ドレープ風 |
| 粘液の帯の幅 m | `_SheetBandWidth` | 0.12 | 束を並べる帯 1 本の幅 |
| 帯の向き 角度 | `_SheetRotation` | 10 | 0 で体の周りを水平に巻く |
| 帯に沿った模様の細かさ | `_SheetAlongScale` | 3 | 帯に沿った方向の模様の細かさ |
| 模様のシード | `_SheetSeed` | 0 | 模様の乱数 |
| 重ねる膜の枚数 | `_SheetLayers` | 2 | 1〜3 |
| 層ごとの回転 角度 | `_SheetLayerTwist` | 8 | 2 枚目以降を回す角度 |
| 2枚目以降の模様のずれ m | `_SheetLayerShift` | 0.08 | 2 枚目以降の模様をずらす量 |
| 層ごとの不透明度倍率 | `_SheetLayerOpacity` | 0.95 | 奥の層ほど薄くする倍率 |
| くびれと玉 / 玉の細かさ | `_SheetBeads` / `_SheetBeadFreq` | 0.55 / 2.2 | 束のくびれと粘液の玉 |
| 束・膜の形 | `_GooStrands` ほか | ネットと同じ | 束の本数・太さ・並ぶ幅・蛇行・融合の粘り・膜の量・穴の間隔・列数・穴の開き具合。[蜘蛛糸の粘液モード](SpiderSilk.md)と同じ名前・同じ意味 |

- シェーダーの中ではキーワード `SC_SURFACE_NET` で切り替えます。インスペクタで値を変えると、キーワードも自動で付け外しされます。**スクリプトで `_SurfaceStyle` を変えるときは、`material.EnableKeyword("SC_SURFACE_NET")` / `DisableKeyword` も一緒に呼んでください**（キーワードが無いと 0 として描きます）。MaterialPropertyBlock では切り替えられません。
- 模様の継ぎ目は Cube のローカル −X（背中側）に来ます。巻きアニメは、高さの順に現れる簡易版です。

### 粘液の形・粘液の膜・粘液の細部（共通）

[繭本体](Cocoon.md#粘液の形共通)と同じ項目・同じ既定値です（帯の平たさ・糊の玉・帯の間の膜・帯の中の筋・重なりの影）。

### レンダーステート（固有）

| 表示名 | 内部名 | 既定値 | 説明 |
|---|---|---|---|
| ステンシル ビット | `_StencilRef` | 128 | 視界ジャックの内壁に立てる目印のビット。**繭本体のマテリアルと同じ値にそろえる** |
| glue を描く画素のステンシル値 | `_GlueStencilRef` | 0 | 体表の繭を描く画素の条件「(ステンシル & 比較ビット) ＝ この値」。0 は従来どおり。32 は[繭プロジェクター](CocoonProjector.md)の目印が立った画素だけに描く |
| glue のステンシル比較ビット | `_GlueStencilReadMask` | 208 | 比べるビット。既定 208 ＝ 内壁の 128 ＋ 蜘蛛糸の芯の 64 ＋ 蜘蛛の体の 16。繭プロジェクターと組むときは 240（＋ 32） |

- 体表の繭は奥行きを無視して描く（ZTest Always）ので、そのままだと手前を通る蜘蛛糸・内壁・手前にいる蜘蛛の体の上に塗ってしまいます。ステンシルの目印でそれを防いでいます。
- ビット 16 は「蜘蛛の体」の目印です。このパッケージのシェーダーは立てません。ワールド側の蜘蛛のシェーダーが、見えている画素にビット 16 を立てると、その画素には繭を塗りません（立てるシェーダーが無ければ、従来の 192 と同じ結果です）。
- どれかのビットを変えたら、`_GlueStencilReadMask` を合計に合わせてください（蜘蛛糸の `_SilkStencilBit` も参照）。
- アバターのシェーダーがビット 16・64・128 を立てる部位には、体表の繭が描かれません。

> **0.7.0 以前から更新した場合**: `_StencilSkipMask`（既定 192）は廃止し、上の 2 項目に分けました。既定値のまま使っていたマテリアルは何もしなくて構いません（新しい既定 0 / 208 になり、蜘蛛の体のビット 16 も避けます）。`_StencilSkipMask` を 192 以外に変えていたマテリアルは、その値を `_GlueStencilReadMask` に入れ直してください（Unity は名前が変わったプロパティの値を引き継ぎません）。

### 投影フィット（固有）

| 表示名 | 内部名 | 既定値 | 説明 |
|---|---|---|---|
| 円筒半径 | `_RadiusFit` | 0.5 | 円筒の半径（Cube に対する割合。0.5 で内接） |
| 円筒高さ | `_HeightFit` | 0.5 | 円筒の半分の高さ（0.5 で Cube いっぱい） |
| 投影の許容距離 | `_ProjectRange` | 0.1 | 円筒の外でも、この距離（m）以内の体の表面には繭を張る。0 で円筒の中だけ |

Cube は少し大きめにして画面上の描画範囲を確保し、繭は「円筒半径」「円筒高さ」で体にぴったり合わせる、という使い分けができます。

### 繭まとめ描きのボリューム（固有）

[CocoonGroupLinker](UdonGimmicks.md#繭のまとめ描きcocoongrouplinker) でまとめた繭を、厚い 1 つの繭（以下「まとめ繭」）として描く設定です。まとめ描きをしていないときは使われません。

内部名に `Bridge` が付く項目は、**繭同士の接続部位**（2 つの部位のあいだを繭で埋めてつなぐ部分）の設定です。内部名は、作成済みのマテリアルと、値を渡す Udon（CocoonGroupLinker など）が名前で参照しているため、そのままにしています。1 つのまとめ繭の中の継ぎ目で、別々のまとめ繭どうしをつなぐものではありません。

| 表示名 | 内部名 | 既定値 | 説明 |
|---|---|---|---|
| まとめ描きの膨らみ m | `_GroupBulge` | 0.045 | 糸の厚みに追加する厚み。0 でまとめ描きでも体表に張り付く描き方に戻る |
| 繭同士の接続部位を作る距離 m | `_GroupBridgeSpan` | 0.1 | 繭同士の接続部位（まとめた部位の間を埋める外皮）を作る、部位の表面どうしの隙間の上限（0〜0.5）。0 で部位の間をつながない |
| 部位間の一体感 | `_GroupShellBlend` | 0.8 | 部位の合流部分を丸める強さ（0〜4）。1 を超えると、脇や股の凹みもまたいで一体の形になる |
| まとめ繭の半径フィット | `_GroupRadiusScale` | 0.75 | 投影円筒に対するまとめ繭の半径の比。大きいアバターで体が突き抜けるときは上げる |
| 部位の軸に沿う強さ | `_GroupAxisFollow` | 0.8 | 部位ごとの軸に巻き模様を沿わせる強さ。0 で全員共通の軸 |
| 軸をつなぐ滑らかさ m | `_GroupAxisBlend` | 0.12 | 軸の向きを混ぜる距離。上げると広い範囲でゆるやかに向きが変わる |
| まとめ繭のレイマーチ最大歩数 | `_GroupMarchSteps` | 80 | まとめ繭の表面を探す計算の最大回数（32〜160）。全身を覆う大きなまとめ繭で穴が開くときは上げる |
| 遠くのまとめ繭の最大歩数 | `_GroupMarchStepsFar` | 60 | 遠くのまとめ繭で使う最大回数。上の値以上にすると減らさない |
| 歩数を減らし始める距離 m | `_GroupMarchFarStart` | 2.5 | カメラから箱の中心までがこの距離までは「まとめ繭のレイマーチ最大歩数」 |
| 遠くの歩数になる距離 m | `_GroupMarchFarEnd` | 5 | この距離より遠いと「遠くのまとめ繭の最大歩数」。間はなめらかに減らす |
| 隠れたまとめ繭を quad 単位で捨てる | `_GroupDepthCut` | ON | 不透明な物の向こうに完全に隠れたまとめ繭を、計算の前に 2×2 画素単位で捨てる（下の注意） |
| 絞った繭同士の接続部位の高さ倍率 | `_GroupBridgeHeightScale` | 1 | 形を絞った接続部位（スクリプトが組の w > 0 で指定したもの）の高さの倍率。木の繭など、組を渡さない使い方では効かない |

- まとめ繭はカメラの深度ではなく、各部位の円筒から形を計算します。左右の目や視点で形が変わりません。その代わり、アバターの実際の形にぴったり沿うのではなく、円筒を組み合わせた近似です。
- まとめ繭は奥行き用と色用の 2 パスで描き、濃い所（不透明度 0.5 以上）だけ奥行きを書きます。
- まとめ繭を描くピクセルでは、最大「まとめ繭のレイマーチ最大歩数」（既定 80、遠くでは 60）の探索（レイマーチ）を 2 パス分行うので重めです。大きく映る場面・多人数での負荷は実機で確認してください。
- 「隠れたまとめ繭を quad 単位で捨てる」は、壁の向こうなどで完全に隠れたまとめ繭の計算を省きます。見えている画素は変わりませんが、次の場面では見えるはずのまとめ繭が欠けることがあります。気になるときは OFF にしてください。
  - 深度テクスチャには入るのに、手前を隠さない物の向こう（キュー 2500 以下で ShadowCaster パスを持つ ZWrite Off の物、alpha to coverage のカットアウトなど）
  - MSAA で、遮蔽物どうしの間の 1 画素より細い隙間の向こう
- 全身を 1 つのまとめ繭で包む使い方（部位 16 個・部位の組ごとの接続部位・端の丸め）もできます。部位と組はスクリプトが MaterialPropertyBlock で渡します（[スクリプトが渡す値](UdonGimmicks.md#まとめ繭の部位を自分で渡すとき)）。

### 糸の厚み（固有）

| 表示名 | 内部名 | 既定値 | 説明 |
|---|---|---|---|
| 糸の厚み m 輪郭の外への膨張 | `_GlueThickness` | 0.06 | 体の輪郭から外へ糸を盛る厚み（m）。0 で体表ぴったり |

### 太さをそろえる（固有）

体に沿って巻いた繭は、首・足首が細く、脚が 1 本ずつ巻かれて、ミイラのように見えます。この値を上げると、**体の一番太い所に合わせた、太さのそろった繭**に近づきます。

| 表示名 | 内部名 | 既定値 | 説明 |
|---|---|---|---|
| 太さをそろえる 0=体に沿う 1=均一な繭 | `_EvenGirth` | 0 | 0 は今までどおり体に沿う繭。1 で、体全体が一番太い所の太さの繭に入る。間は少しずつ太る |
| そろえた繭の太さの足し引き m | `_EvenGirthMargin` | 0.02 | 一番太い所の半径に足す量（m）。衣装のふくらみ（スカートなど）で体の繭がはみ出すときは上げる。太すぎると感じたら下げる（マイナスも可） |

- **しくみ**: 体の軸に沿って、両端が丸い筒（カプセル）を考えます。筒の半径は「この値 ×（一番太い所の半径 + 足し引き + 糸の厚み）」です。画素ごとに、筒の面と体の繭（今までの描き方）のうち**手前にある方**を描きます。値が小さいうちは筒が体の中に隠れていて見えず、上げるにつれて細い所（首・脚の間・足首）から先に筒で埋まり、1 で体の繭がすべて筒の中に入ります。Web で例えると、子要素（腕・脚）の外側に、一番幅の広い子に合わせた `min-width` の親の箱をかぶせ、その幅を 0 から 100% まで動かすようなものです。
- 筒は深度テクスチャを使わずに式で形を求めるので、体の輪郭の外（脚の間・首の横の背景）にも描けます。筒より手前に物（柱・ほかの人）があれば、その画素には描きません。
- 帯の模様は角度と高さで決まるので、体の繭と筒の境目でも帯は続きます。
- **筒の位置と太さ**: [繭プロジェクター](CocoonProjector.md#太さをそろえる)の駆動スクリプトの `Cocoon Renderer` にこの箱を入れると、駆動スクリプトが毎フレーム、捕まった人の骨から「体の軸に沿った上端・下端」と「軸から一番遠くまで張り出した所までの半径」を計算して渡します（`_EvenGirthA` / `_EvenGirthB`。腕を下ろして立っていれば、一番太い所は腕の外側）。繭プロジェクターと組むのに渡されていないとき（Cocoon Renderer が空、誰も捕まっていない）は、筒を描きません。繭プロジェクターと組まないときは、この箱の円柱（円筒半径・円筒高さ）を、箱からはみ出さない太さに収めて筒にします。
- 筒は**箱の外には描きません**。箱が筒より小さいと、はみ出した所は箱の面の近くでほつれて（`_GooEdgeFray`）切れます。駆動スクリプトの筒を使うときは、箱を筒が入る大きさにしてください（駆動スクリプトの `girthBottom` / `girthTop` / `girthRadius` で、最後に渡した筒を読めます）。
- 繭プロジェクターと組む（`_GlueStencilRef` 32）ときは、目印の無い画素（体の輪郭の外）の筒をパス 6 が描きます。目印は体にだけ立ちますが、筒は式で求めた形を手前の物と比べて描くので、床・壁・隣の人に糸がにじむことはありません。
- 筒の中から見たとき（捕まった本人の一人称、抱きついている人）は筒を描きません（中からの見え方は視界ジャックの役目です）。
- 繭のまとめ描き（CocoonGroupLinker）では使えません（0 と同じ）。
- 筒の陰影は筒の面の向きで付けるので、丸い両端も丸く見えます。帯の模様は箱の軸のまわりの角度と高さで決まります。
- 筒の模様に隙間があるとき（蜘蛛の巣ドレープなど）は、隙間から奥の体の繭が見えます。

### 巻きの端のほつれ（固有）

| 表示名 | 内部名 | 既定値 | 説明 |
|---|---|---|---|
| 巻きの端のほつれ幅 m | `_GooEdgeFray` | 0.03 | 円筒の上下端・外周に近づくほど帯を細らせ、帯ごとに違う位置で途切れさせる幅。0 でまっすぐな端 |

### 巻きアニメ（固有）

| 表示名 | 内部名 | 既定値 | 説明 |
|---|---|---|---|
| 巻きアニメ有効 | `_WindEnable` | OFF | ON で巻きアニメを使う。OFF は完成した繭 |
| 巻きの進み具合 | `_WindProgress` | 1 | 0（巻き始め）→ 1（完成） |

- 糸の先端が体の周りを回りながら進み、層を 1 枚ずつ往復して巻いていきます。帯の間の膜も進み具合に合わせて育ちます。視界ジャックの内壁にも同じ巻き方が出ます。
- 進み具合を時間で動かすには、Udon から MaterialPropertyBlock で `_WindProgress` を書き換えます（駆動スクリプトは同梱していません）。インスペクタでスライダーを動かして見た目を確認できます。

### 他の部位を巻かない（固有）

| 表示名 | 内部名 | 既定値 | 説明 |
|---|---|---|---|
| 他の部位を除く面の向き -1で無効 | `_WrapFacing` | -1 | -1 より大きくすると、軸から見て外を向いていない面を巻かない |

円筒は体より太めに作るので、輪の中に入り込んだ別の部位（胸の輪に入った腕の内側、手首の輪に入った太ももなど）まで巻いてしまうことがあります。巻いている部位の表面は軸から外を向く（向きの値 ≒ 1）のに対し、入り込んだ別の部位のこちら側の面は内を向く（0 未満）ので、この値で除けます。目安は 0.2 です。全身を覆う大きな繭では -1（無効）のままにしてください。

### 床・天井（固有）

| 表示名 | 内部名 | 既定値 | 説明 |
|---|---|---|---|
| 床/天井テクスチャ 蜘蛛の巣など | `_GroundTex` | 黒（透明） | 床・天井と判定した所に貼るテクスチャ。未設定なら何も描かない |
| 床/天井テクスチャの色 | `_GroundColor` | (1,1,1,1) | テクスチャに掛ける色 |
| 床判定のサンプル間隔 m | `_GroundDetectScale` | 0.05 | 面の向きを調べる間隔（実寸 m）。距離に関係なく同じ大きさで判定する |
| 水平とみなす法線Y | `_GroundNormalY` | 0.8 | 面の上向き度合いがこれ以上なら床・天井とみなす（約 37°）。上げるほど厳しくなる |

- 床の高さは問いません。段差やジャンプ中でも床を見分けられるので、足元まで糸を描けます。
- 足の甲・つま先など、体の水平な上面も床とみなされることがあります。「水平とみなす法線Y」を上げると減らせます。

Render Queue・Enable GPU Instancing・Double Sided Global Illumination（Unity 標準の項目）です。

## 描画について

7 つのパスで描きます。

| パス | 名前 | 役割 |
|---|---|---|
| 0 | `VISIONJACKDEPTH` | 視界ジャックの内壁の奥行きを書く（発火中だけ） |
| 1 | `VISIONJACK` | 内壁の色を塗り、ステンシルに目印を書く（発火中だけ） |
| 2 | （名前なし） | 通常の視点で体表に繭を塗る（糸の厚み・床天井・まとめ描きを含む）。ミラー内では描かない |
| 3 | （名前なし） | ミラーの中で体表に繭を塗る |
| 4 | `GROUP_SHELL_DEPTH` | まとめ繭の奥行きを書く（代表の繭だけ） |
| 5 | `GROUP_SHELL` | まとめ繭の色を塗る（代表の繭だけ） |
| 6 | `EVEN_GIRTH` | [太さをそろえた](#太さをそろえる固有)繭の筒のうち、繭プロジェクターの目印が無い画素を塗る（通常の視点とミラーの両方） |

- 描画順は `Transparent` です。パス 0・1・4・5・6 は、使わないときは頂点の段階で潰れて何も描きません（パス 6 は「太さをそろえる」が 0 より大きく、`_GlueStencilRef` が 0 でないときだけ）。
- パス 2・3 も、「太さをそろえる」が 0 より大きいときは、体の繭と筒の手前の方を描きます。
- **静的バッチングは自動で無効**になります（`DisableBatching`）。

## 注意・制約

- **深度が前提・PC 専用**です。一人称の自分の体は深度に入らないので、自分の体には張り付きません（一人称は視界ジャックが担当します）。
- 円筒（＋許容距離）の中にある別の物（近くの他プレイヤー、円筒に入った床など）にも張り付くことがあります。円筒の大きさと許容距離を絞って調整してください。
- アバターの輪郭では深度が急に変わるため、糸が少しにじむことがあります。
- 体表に張り付くパスは、糸の厚みのために 1 ピクセルあたり 24 回、床判定で 4 回、「他の部位を巻かない」が有効ならさらに 4 回深度を読みます。大きく映ると負荷が上がります。視線が円筒（代表は箱）に届かない画素（壁の向こう・箱の角など）は、読む前に捨てます。
- ポイントライト・スポットライトは効きません。影も落としません。
- VR のシングルパスステレオに対応しています。

## 確認チェックリスト

1. 影付きの Directional Light を置く。**消すと体の繭が出なくなる**ことで前提を確認する。
2. Cube を胴に合わせ、デスクトップ・第三者カメラから見て、体のシルエットに沿って糸が乗ること（浮いた筒ではなく表面に張り付くこと）。出ないときは Cube が体を包んでいるか（位置・スケール・向き）を確認する。
3. 対象が歩いたり回ったりしても追従し、腕・地面に大きくはみ出さないこと。はみ出す・欠ける場合は「円筒半径」「円筒高さ」で調整する。
4. ミラーにも同じ体表の繭が映ること。
5. VR 実機で、左右の目のずれと負荷を確認する。
