# 糸の網（SpiderSilkNet）

シェーダー名: `mecaota/SpiderSilkNet`

[← README に戻る](../README.md) ｜ 関連: [共通機能（インスペクタ・質感の継承・プリセット）](CommonFeatures.md) ／ [Udon ギミック](UdonGimmicks.md)

## ひとことで

穴の大きさがばらばらな**不規則な網**を描くシェーダーです。絵柄は 2 種類あります。

- **籠目**: 上下左右につながる網。人が入る大きさの籠（同梱の `SilkNetCage` メッシュ）に貼ります。
- **張り巣**: 板 1 枚に収まる不規則な張り巣。体に当たった巣・着弾した巣の板（同梱の `SilkNetPlane17` / `SilkNetPlane33` メッシュ）に貼ります。

- 網の形は、あらかじめ画像に焼いたもの（同梱）を読むだけです。実行中に網の形は計算しません。
- 塗りは蜘蛛糸の粘液モードと同じで、質感（粘液の色・ツヤ・トゥーン・リム）は蜘蛛糸から**継承**します（[質感の継承](CommonFeatures.md#質感の継承)）。
- [蜘蛛の巣](SpiderWeb.md)と同じ「体に覆いかぶさる変形」が使えます（平面メッシュのとき）。
- 対応環境: Unity Built-in Render Pipeline。PC 向けです。Quest（Android）では未検証です。

## こんなときに使う

- 捕まえた人を入れておく、吊るした籠
- 体に当たって貼り付いた網、壁や床に着弾した巣の板
- 投げつけて体にかぶせる網（体に覆いかぶさる変形）

## クイックスタート

### 籠を置く

1. 空の GameObject に **MeshFilter** と **MeshRenderer** を付け、Mesh に `Runtime/SilkNet/Meshes/SilkNetCage` を入れます（高さ 2.2 m・半径 0.42 m、原点が籠の中心）。
2. MeshRenderer の Materials に標準マテリアル `Runtime/SilkNet/Materials/SilkNet_Cage` を入れます。自分のマテリアルを作るときは、Shader を `mecaota/SpiderSilkNet` にして、プリセット **「籠目の籠」** を押し、下の「糸の網の絵柄の状態」欄で **「標準の籠目を入れる」** を押します。
3. 色やツヤは、紫の「蜘蛛糸の質感（継承）」欄で継承元の蜘蛛糸マテリアルを選んで変えます。

### 張り巣の板を置く

1. Mesh に `SilkNetPlane17`（軽い）か `SilkNetPlane33`（体に覆いかぶさる変形用）を入れます。平面は床に置いた向き（表が真上 = +Y）です。
2. Materials に標準マテリアル `SilkNet_WebBoard` を入れます。自分で作るときは、プリセット **「張り巣の板」** と **「標準の張り巣を入れる」** を押します。

> 絵柄の画像（形・補助・被覆率の 3 枚）が入っていないマテリアルは何も描きません。インスペクタに黄色の警告が出たら、「糸の網の絵柄の状態」欄のボタンで標準の絵柄を入れてください。

## しくみ（シェーダー初心者向け）

1. **形は画像から読む**: 網の形は、Editor で「一番近い糸までの距離」を画素ごとに書いた画像に焼いてあります（距離の画像。SDF とも呼びます）。シェーダーは距離を読んで、負の所（糸の内側）だけを塗ります。距離の画像は拡大してもふちがなめらかなので、512 角の画像でも、近くで見たときに崩れにくくなります。
2. **膜の量**: 形の画像には「糸だけ」と「糸の間に膜（水かき）を張った形」の 2 つの距離が入っています。`_NetFill` でその間をなめらかに補間するので、焼き直さずに膜の量を変えられます。
3. **塗り**: 明部と影部の 2 色で平らに塗り、光の反対側の縁に陰の帯、ふちに輪郭線を引きます。色の値は継承した質感（21 項目）を使います。
4. **3 つのパス**: 深度（芯だけ）→ 裏向きの面 → 表向きの面 の順に描きます。両面を一度に描くと、籠の奥の糸が手前の膜の上に乗って見えることがあるためです。
5. **遠くでは簡略化**: 一定の距離より遠いと、細部の画像を読むのをやめて一色で塗ります。さらに遠いと、籠の奥の壁を描きません。

## インスペクタの項目

インスペクタの並び順で載せています。質感（紫）の 21 項目は [共通機能のページ](CommonFeatures.md#継承する-21-項目) にまとめています。

### 糸の網の絵柄（固有）

| 表示名 | 内部名 | 既定値 | 説明 |
|---|---|---|---|
| 絵柄: 形 | `_BakedShape` | なし | 焼いた形の画像（2D Array）。下の欄のボタンで標準の絵柄を入れる |
| 絵柄: 補助 | `_BakedDetail` | なし | 糸のふちの向き・糸の半径・糸ごとの乱数の画像（2D Array） |
| 絵柄: 被覆率 | `_BakedCoverage` | なし | 遠くで使う、糸と膜の面積の画像（2D Array） |
| 使う枚 -1で種から | `_NetSlice` | 0 | 配列の何枚目の絵柄を使うか。-1 で下の「ずらしの種」から選ぶ |
| ずらしの種 | `_NetSeed` | 0 | 籠目は左右反転とずらし、張り巣は 90 度ごとの回転と反転に使う乱数。部品ごとに MaterialPropertyBlock で変えると、同じマテリアルでも見た目が揃わない。プリセットには保存されない |
| 並べる回数 整数 xy | `_NetTiling` | (1,1,0,0) | 籠目を UV 1 あたり何回並べるか（整数に丸める）。張り巣は板 1 枚なので使わない |

絵柄の種類（籠目か張り巣か）と枚数は、インスペクタが「絵柄: 形」の画像から自動で入れます（隠し項目 `_NetKind`・`_NetSliceCount`・`_NetBakeRange`）。

### 糸の網の形（固有）

| 表示名 | 内部名 | 既定値 | 説明 |
|---|---|---|---|
| 糸の太さの倍率 | `_NetWidth` | 1 | 糸の太さに掛ける倍率（0.3〜2） |
| 膜の量 | `_NetFill` | 0.25 | 糸の間に張る膜の量。0 で糸だけ |
| 板の縁で糸と膜を細らせる幅 UV | `_NetEdgeFade` | 0.03 | 張り巣だけ。板の縁に近い糸と膜を細らせ、縁をでこぼこにする幅 |
| 糸の断面の陰 | `_NetProfileShade` | 1 | 糸の丸みと陰の帯の強さ |
| メッシュの丸みの陰 | `_FormShade` | 0 | メッシュの面の向きに沿って明暗を付ける強さ（籠を立体的に見せる） |

`_NetMerge` は使われなくなった項目で、古いマテリアルのために残してあります（インスペクタには出ません）。

### 糸の網の裏側（固有）

| 表示名 | 内部名 | 既定値 | 説明 |
|---|---|---|---|
| 裏側の描き方 | `_BackMode` | ThinStrands | 裏向きの面（籠の奥の壁）の描き方。下の表 |
| 籠の半分の大きさ 物体座標 | `_NetCageExtent` | (0,0,0,0) | カメラが籠の中にいるかを決める箱の大きさ（中心から各軸の端まで）。中にいるときは、裏向きの面も表と同じに描く。0 なら判定しない。`SilkNetCage` なら (0.47, 1.1, 0.47) |
| 奥の壁の色 | `_BackTint` | (0.70,0.73,0.80,1) | 奥の壁の描き方で掛ける色 |
| 奥の壁の糸の太さ | `_BackWidth` | 0.55 | 奥の壁の描き方での糸の太さの倍率 |

| 裏側の描き方 | 動き |
|---|---|
| Same（0） | 裏向きの面も表と同じに描く。張り巣の板はこれ |
| ThinStrands（1） | 奥の壁の描き方（膜なし・細い糸だけ・奥の壁の色）。籠を外から見たとき、奥の網がうるさくならない |
| Hidden（2） | 裏向きの面を描かない |
| InnerCage（3） | 内側の籠（`SilkNetCageInner`）用。外から見たときだけ、こちらを向いた面を奥の壁の描き方で描く。カメラが籠の中なら描かない |

外の籠を Hidden、内側の籠（面を裏返して 0.92 倍にしたメッシュ）を InnerCage にすると、外から奥の壁だけが見える組み合わせになります。

### 糸の網の距離による簡略化（固有）

| 表示名 | 内部名 | 既定値 | 説明 |
|---|---|---|---|
| 一色で塗る距離 m | `_NetSimpleDistance` | 6 | これより遠い所は細部の画像を読まず、一定の太さと陰で塗る（1 m かけてなめらかに切り替える） |
| 奥の壁を消す距離 m | `_BackHideDistance` | 10 | 物体の原点がカメラからこれより遠いと、奥の壁の描き方の面を描かない |

### 体に覆いかぶさる変形（固有）

[蜘蛛の巣](SpiderWeb.md#体に覆いかぶさる変形固有)と同じ名前・意味・既定値です。項目の説明と駆動スクリプトの使い方は [Udon ギミックのページ](UdonGimmicks.md#体に覆いかぶさる変形drape) を参照してください。

- UV で網の位置を決めるので、平面メッシュ（`SilkNetPlane33` など）に貼ります。籠には使いません。
- 「体に覆いかぶさる変形 有効」（`_DrapeEnable`）を ON にすると、シェーダーキーワード `_NET_DRAPE` が付きます。インスペクタでは自動で付け外しされます。**スクリプトで `_DrapeEnable` を書いたときは `SpiderCocoonShaderGUI.SyncKeywords` を呼んで**キーワードをそろえてください（Editor 専用）。
- 標準マテリアル `SilkNet_Drape` は、ドレープ用の板の絵柄を入れ、この変形を ON にしたものです。

### 糸の網の絵柄の状態

各カテゴリの下にある欄です。今の絵柄の種類と枚数を表示し、標準の絵柄を入れるボタン（「標準の籠目を入れる」「標準の張り巣を入れる」「ドレープ用の板を入れる」）があります。

### 詳細設定

Render Queue・Enable GPU Instancing・Double Sided Global Illumination（Unity 標準の項目）です。

## 絵柄の焼き直し

メニュー **Tools > SpiderShader > 糸の網 > 絵柄を焼き直す（籠目・張り巣・ドレープ用の板）** で、3 種類の絵柄を決まった種で焼き直し、`Runtime/SilkNet/Patterns/` の PNG と JSON を上書きします（確認ダイアログが出ます）。

- 絵柄は同梱されているので、ふだんは焼き直す必要はありません。生成器を直して、パッケージの版を上げるときだけ使います（焼き直すたびにリポジトリの履歴が増えるため）。
- 同じ種なら、何度焼いても同じ画素になります。
- PNG は 512 角の絵柄を縦に並べた 1 枚の画像で、取り込み設定の「2D Array」で配列になります。取り込み設定（2D Array・リニア・ミップあり・PC は BC5 / BC7 / R8 など）は、取り込みのたびに自動でこの値に戻ります。手で変えても戻るので、触らないでください。

## メッシュの生成

メニュー **Tools > SpiderShader > 糸の網 > メッシュを作る（籠・内側の籠・平面）** で、4 つのメッシュ（`SilkNetCage`・`SilkNetCageInner`・`SilkNetPlane17`・`SilkNetPlane33`）を作り直します。

- メッシュも同梱されているので、ふだんは作り直す必要はありません。
- 保存先はパッケージの `Runtime/SilkNet/Meshes/` です。パッケージに書き込めないとき（Package Cache の中など）は `Assets/SpiderSilkNet/Meshes/` に作ります。
- すでにあるメッシュは、GUID を保ったまま中身だけ入れ替えるので、使っている MeshFilter の参照は外れません。
- 籠の UV は「周を 1 回で絵柄 1 枚、縦は約 0.85 枚」になるように付けてあり、並べる回数 (1, 1) で絵柄の画素がほぼ正方形になります。

## 描画について

- 描画順は `Transparent`（3000）です。蜘蛛糸（`Transparent-10`）より後、巣・繭と同じです。ステンシルは使いません。
- 3 つのパスで描きます。
  - `DEPTHSOLID`: 色は塗らず、不透明度 0.5 以上の芯だけ深度を書きます。描かない面の画素は捨てます。
  - `BACK`: 裏向きの面（Cull Front）を先に塗ります。
  - `FRONT`: 表向きの面（Cull Back）を後に塗ります。
- 籠の中か外かの判定と、奥の壁を消す距離に物体の座標を使うため、`DisableBatching` タグで静的バッチングを止めています。
- ポイントライト・スポットライトは効きません（メインの Directional Light と環境光だけを使います）。影も落としません。

## 注意・制約

- 絵柄の画像が無いと何も描きません（標準マテリアルには入っています）。
- 「籠の半分の大きさ」はメッシュに合わせて設定します。籠を拡大・縮小しても物体座標なので値は変えなくて構いませんが、別のメッシュを使うときは測り直してください。
- 体に覆いかぶさる変形を使うときは、GameObject の Static と、マテリアルの **GPU Instancing を OFF** にしてください（[Udon ギミックの注意](UdonGimmicks.md#drape-の注意)）。
- 半透明なので、網どうしが重なると前後関係が不正確になることがあります（半透明の一般的な制約）。

## 確認チェックリスト

1. 標準マテリアル `SilkNet_Cage` を `SilkNetCage` に貼ると、籠目の網が見えること。外から見て、奥の壁が細い糸で描かれること。
2. カメラを籠の中に入れると、周りの網がすべて表と同じに描かれること。
3. `_NetFill` を動かすと、焼き直さずに膜の量が変わること。
4. カメラを 6 m 以上離すと、境目で太さが飛ばずに一色の塗りへ移ること。
5. 継承元の蜘蛛糸の質感（紫の項目）を変えると、網の色にすぐ反映されること。
