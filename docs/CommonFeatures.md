## インスペクタの見方

このパッケージのシェーダー（繭プロジェクター `CocoonProjector` を除く）は、専用のインスペクタで表示されます。項目は lilToon のようにカテゴリごとの折りたたみ枠に分かれ、枠の色で種類が分かります。

| 色 | 枠 | 中身 |
|---|---|---|
| 緑 | プリセット | よく使う設定をボタン 1 つで入れる（[プリセット](#プリセット)） |
| 紫 | 質感 | 粘液の色・ツヤ・陰影・リムライト。蜘蛛糸で決めて、ほかのシェーダーへ継承する（[質感の継承](#質感の継承)） |
| 青 | 〇〇（共通） | 複数のシェーダーが同じ名前で持つ値 |
| オレンジ | 〇〇（固有） | そのシェーダーだけの機能 |
| 黄緑 | 焼き込みの状態 | 蜘蛛の巣ドレープだけ。模様の焼き込み（[蜘蛛の巣ドレープ](SpiderWebDrape.md#焼き込み)） |
| 紫 | lilToon に焼き込む（軽量化） | 蜘蛛の巣だけ。巣を lilToon に焼き込む確認画面を開く（[蜘蛛の巣](SpiderWeb.md#巣を-liltoon-に焼き込む軽量化)） |

上から「プリセット → 質感 → 青・オレンジの各カテゴリ →（焼き込みの状態・lilToon に焼き込む）→ 詳細設定」の順に並びます。

- **詳細設定**: Render Queue・Enable GPU Instancing・Double Sided Global Illumination（Unity 標準の項目）です。
- **その他（未分類）**: カテゴリ表に登録されていないプロパティがあると、ここに表示されます（通常は出ません）。
- 枠の開閉状態は Unity に記憶されます。
- 同じ名前の値でも、シェーダーによって単位や大きさが違うことがあります（例: 「玉の細かさ」は蜘蛛糸ではメートル単位、巣では巣の UV 単位）。

> Editor スクリプト（パッケージの `Editor/` フォルダ）が無い環境でもシェーダーは動き、Unity 標準のインスペクタで表示されます。ただし、蜘蛛の巣ドレープの焼き込み・巣の lilToon への焼き込みと、質感の継承の自動同期は使えなくなります。

## 質感の継承

蜘蛛糸（[SpiderSilk](SpiderSilk.md)）のマテリアルで決めた**質感**（粘液の色・陰影・輪郭線・不透明度・透け・ハイライト・粘液感・トゥーン・リム）を、蜘蛛の巣・繭・繭デカール・蜘蛛の巣ドレープのマテリアルが受け継ぐ仕組みです。継承元の蜘蛛糸を変えると、継承しているマテリアルにすぐ反映されます（Ctrl+Z も連動します）。

| 役割 | シェーダー |
|---|---|
| 継承元（質感を決める側） | `mecaota/SpiderSilk` |
| 継承先（質感を受け継ぐ側） | `mecaota/SpiderWeb`・`mecaota/Cocoon`・`mecaota/CocoonDecal`・`mecaota/SpiderWebDrape` |

### 何をしているか（初心者向け）

- Web でいえば、「テーマの CSS 変数を、編集するたびに各ページのスタイルへ書き写す」仕組みです。
- 継承先の .mat ファイルには普通の値として保存されます。**実行時の処理はゼロ**で、VRChat では普通のマテリアルとして動きます。
- 継承先のマテリアルは「どの蜘蛛糸マテリアルを継承元にするか」を、描画に使わない隠しプロパティ `_SilkLookLink` に記録します。普通のプロパティなので、複製・Material Variant・Undo でリンクも一緒に動きます。
- 継承元を指定していない継承先は、蜘蛛糸シェーダーの既定値（標準の粘液糸の質感）にそろいます。
- 継承先では質感を編集できません（インスペクタでは読み取り専用）。違う質感にしたいときは、別の蜘蛛糸マテリアルを継承元にします。

### 継承する 21 項目

| グループ | 表示名 | 内部名 | 既定値 | 説明 |
|---|---|---|---|---|
| 粘液の色と陰影 | 粘液感 0で乾いた糸 | `_GooAmount` | 1 | 下げると太り・玉・膜・ツヤ・透けが一緒に弱まり、0 で乾いた細い糸に近づく |
| | 明部の色 | `_GooColor` | (0.88,0.87,0.94,1) | 光が当たる側の色 |
| | 影部の色 | `_GooShadowColor` | (0.6,0.58,0.72,1) | 影側の色 |
| | 影の広さ | `_GooShade` | 0.12 | 明部と影部の境目をずらす量 |
| | 輪郭線の色 a=濃さ | `_GooOutlineColor` | (0.33,0.32,0.45,0.85) | 糸の縁に引く線の色 |
| | 輪郭線の太さ | `_GooOutline` | 0.14 | 糸の半径に対する輪郭線の太さ |
| | 不透明度 | `_GooOpacity` | 0.92 | 全体の不透明度 |
| | 中心の透け | `_GooClarity` | 0.25 | 糸の中心ほど透ける量（ゼリーのような見え方） |
| 粘液のハイライト | ハイライト色 a=濃さ | `_GooGlossColor` | (1,1,1,1) | ツヤの色 |
| | ハイライトの強さ | `_GooGloss` | 1 | ツヤの強さ |
| | ハイライトの太さ | `_GooGlossWidth` | 0.14 | ツヤの筋の太さ |
| | ハイライトを光源側へ | `_GooGlossOffset` | 0.3 | ツヤを光源側へ寄せる量 |
| | ハイライトの途切れ | `_GooGlossBreak` | 0.3 | 0 で連続した筋、1 で点々 |
| トゥーン陰影 | トゥーン段階数 | `_ToonSteps` | 1 | 陰影の段数。1 でアニメ風の 2 色 |
| | 段差の柔らかさ | `_ToonSmooth` | 0.03 | 段の境目のぼかし |
| | 環境光の底上げ | `_AmbientBoost` | 0.35 | 環境光で全体を明るくする量 |
| | シーン光の反映度 | `_LightInfluence` | 0.35 | 0 で照明に関係なく一定の明るさ、1 で照明の明るさに大きく依存 |
| リムライト | リムライト色 | `_RimColor` | (0.8,0.9,1,1) | 輪郭（シルエットの縁）を光らせる色 |
| | リム幅 / 鋭さ | `_RimPower` | 4 | 大きいほど細い |
| | リム強さ | `_RimStrength` | 0.3 | 強さ |
| | リムの下限/全体発光 | `_RimFloor` | 0.05 | 0 より大きいと正面にも発光が乗る（「縁は光るのに正面だけ暗い」を防ぐ） |

継承しないもの（各マテリアルの値のまま）:

- 同じ名前でも**単位がシェーダーごとに違う**値（玉の細かさ・太さ倍率・膜の量・糸の太さ・巻き数・レイヤーなど）。蜘蛛糸は軌跡に沿ったメートル、巣は巣の UV、繭は円筒の UV で測るので、同じ数字でも見た目が変わってしまうためです。
- 形・動き・変形ギミックの値、乾いた糸モード専用の陰影、太さの揺らぎ、帯の中の筋の濃さ。

### 使い方

**継承先（蜘蛛の巣・繭・繭デカール・蜘蛛の巣ドレープ）のインスペクタ**

紫の「蜘蛛糸の質感（継承）」欄で操作します。

| 操作 | 内容 |
|---|---|
| 継承元の蜘蛛糸 | 継承元の蜘蛛糸マテリアルを選ぶ。▼ でプロジェクト内の一覧から選べる。「なし（蜘蛛糸シェーダーの既定値）」も選べる |
| 継承元を開く | 継承元のマテリアルを別ウィンドウで編集する |
| 場所 | 継承元を Project ウィンドウで示す |
| 今の質感から新しい継承元を作る… | 今の見た目のまま、専用の継承元を作ってリンクする（継承中なら、その継承元の Material Variant として作る） |
| 継承している値を見る（変更不可） | 継承中の 21 項目を読み取り専用で表示する |

**継承元（蜘蛛糸）のインスペクタ**

- 紫の質感カテゴリの見出しに「（蜘蛛の巣・繭・繭デカール・蜘蛛の巣ドレープへ継承）」と付きます（インスペクタの「繭デカール」は、体に張り付く繭のことです）。
- このマテリアルを継承元にしているマテリアルがあるときは、「この質感を継承しているマテリアル（N 個）」欄に継承先の一覧が出ます。「まとめて選択」で全部を選択できます。
- 粘液モードが OFF の蜘蛛糸を継承元にしても、継承先は粘液の塗りで描かれるので、粘液の色・ツヤの値が使われます。

**よくある使い方**

- この巣だけ色を変えたい → 巣のインスペクタで「今の質感から新しい継承元を作る…」→ できた継承元で色を変える。
- 「この糸と同じ質感で、不透明度だけ違う」継承元が欲しい → 蜘蛛糸の **Material Variant** を作って継承元にする。
- 継承先の Material Variant は、親の継承元を受け継ぎます（子で別の継承元を選ぶこともできます）。
- [プリセット](#プリセット)を継承先に当てても質感は変わりません。継承元の蜘蛛糸に当てると継承先にも伝わります。

**スクリプトでマテリアルを作るとき（Editor 専用 API）**

- `new Material(既存の巣のマテリアル)` で作ればリンクも複製されます。
- シェーダーから作るときは `SpiderSilkLook.SetSource(new[]{ mat }, 継承元)` か `SpiderSilkLook.CopySourceFrom(mat, 既存のマテリアル)` を呼びます。`AssetDatabase.CreateAsset` の前に呼んだ場合はリンクだけが書かれ、アセットになった後の自動同期で値がそろいます。`SetSource` は、設定できなかったときに false を返します（`CopySourceFrom` に戻り値はありません）。
- 継承先の質感をスクリプトで `SetFloat` しても、Editor の自動同期で継承元の値に戻ります（実行中の MaterialPropertyBlock は影響を受けません）。

### いつ同期されるか

- インスペクタでの変更・Undo / Redo・プリセット適用・.mat の取り込み（バージョン管理での更新など）・Editor 起動時・Play 終了時に、1 フレームにまとめて同期します。ほかに 2 秒ごとの見回りがあります（Undo を通らないスクリプトの書き込み、継承元の Variant の親の変更など）。
- **Play 中は同期しません**（実行時のスクリプトが .mat を書き換えることがあるため）。
- 自動同期は変更の印（SetDirty）を付けるだけです。保存は Ctrl+S / Save Project で行います。メニュー **Tools > SpiderShader > 質感の継承を同期** と、**VRChat の Build & Upload の直前**（VRChat SDK があるとき）は、同期して保存までします。
- 自動同期で書き換えるのは `Assets/` 以下のマテリアルだけです。VPM などで入れた他のパッケージの中のマテリアルは書き換えません（合わせるときはメニューの「質感の継承を同期」を使います）。
- 継承元を削除すると、継承先は値を保ったまま「継承元が見つかりません」の警告になります（自動で既定値には戻しません）。削除時には継承先の一覧が Console に出ます。
- 継承元の欄以外の方法（Revert all overrides・Reset・スクリプトでの丸ごと上書きなど）でリンクが外れたり変わったりしたマテリアルは、自動同期で書き換えずに警告します。意図した変更なら継承元の欄で選び直してください。

### 古いバージョンから更新したとき

- 質感 21 項目の既定値は、標準の粘液糸の質感（トゥーン 1 段・リムの下限 0.05・不透明度 0.92 など）にそろえています。
- 継承元を指定していない巣・繭・繭デカール・蜘蛛の巣ドレープのマテリアルは、自動で蜘蛛糸シェーダーの既定値にそろいます。そろえる前の値は Console に記録され、そのマテリアルのインスペクタに **「そろえる前の質感で継承元を作る…」** ボタンが出ます（押すと元の見た目の継承元を作ってリンクします）。値の控えは `Library/SpiderSilkLook_PreReset.txt` にも保存されるので、Editor を再起動しても残ります。
- 確実に元の見た目を残したいときは、更新前にマテリアルを控えておいてください。

## プリセット

マテリアルのインスペクタ先頭にある**緑色の「プリセット」欄**から、よく使う設定をボタン 1 つで入れられます（Ctrl+Z で戻せます）。

### 何をしているか（初心者向け）

- プリセットは `SpiderShaderPreset` という小さなアセット（.asset）で、「どのシェーダー用か」と「プロパティ名 → 値」の一覧を持っています。ボタンを押すとその値をマテリアルに書き込むだけです。Web でいえば、保存しておいた入力値をフォームへ流し込む機能です。
- 値を入れたあと、シェーダーの機能スイッチ（キーワード。例: 粘液モードの `_GOO_ON`）も値に合わせて付け直します。
- 今のマテリアルと値がすべて一致するプリセットは**緑の太字**になります（標準設定のままかがひと目で分かります）。
- プロジェクト内のプリセットはどこに置いても自動で集められ、同じシェーダー用のものだけがカテゴリ別に並びます。

### 使い方

| 操作 | 内容 |
|---|---|
| ボタンをクリック | 適用する。同じシェーダーのマテリアルを複数選んでいれば全部に入る。Material Variant で親がロックした値は飛ばす |
| 「巣の形・配置（個別）も上書きする」 | OFF にすると、巣の形・扇形、蜘蛛の巣ドレープの形・焼き込み設定・重なりなど、メッシュごとに決まる値を今のまま残す |
| 「変形ギミック（接触追従・覆いかぶさり）も上書きする」 | OFF にすると、Udon の仕掛けと組で使う「接触追従の変形」「体に覆いかぶさる変形」「近接表示」の値を今のまま残す |
| 今の設定をプリセットとして保存… | 表示名・カテゴリ・説明（ボタンのツールチップになる）と、保存する項目（カテゴリ単位。「すべて」「見た目だけ」「なし」ボタンあり）を選び、保存先を指定する |
| ボタンを右クリック | 「プロジェクトで表示」「プリセットを選択（名前・説明を編集）」「このマテリアルの値で上書き保存」 |

- 標準プリセットを上書きしようとすると確認ダイアログが出ます（「別名で保存…」「キャンセル」「それでも上書き」）。
- プリセットに保存されない値: Udon が実行中に渡す値（`_PullCount`・`_DrapeCount`・`_ClipLine`・`_GravityUseUV`・`_GravityLineLength`）、蜘蛛の巣ドレープの焼き込み結果、継承先での質感。描画順（Render Queue）は、マテリアルで個別に変えたときだけ保存します。
- 繭・繭デカール・蜘蛛の巣ドレープには標準プリセットがありませんが、自分で保存したプリセットは使えます。

## Editor のメニュー一覧

| メニュー | 内容 |
|---|---|
| Tools > SpiderShader > 質感の継承を同期 | すべての継承先を継承元に合わせて保存し、結果をダイアログで表示する（Play 中は実行しない） |
| Tools > SpiderShader > 質感プロパティの一致チェック | 質感 21 項目の定義が全シェーダーで一致しているかを調べる（シェーダーの取り込み後にも自動で実行。一致しない間は自動同期を止める） |
| Tools > SpiderShader > 保守 > 親と同じ値の上書きを掃除（質感） | 継承先の Material Variant で、親と同じ値なのに残っている質感の上書きを外す（確認ダイアログあり。Ctrl+Z では戻せない） |
| Tools > SpiderShader > Generate WebPlane Mesh... | 蜘蛛の巣用の細かく分割された平面メッシュを作る（[詳しく](SpiderWeb.md#webplane-メッシュの生成ツール)） |
| Tools > SpiderShader > Regenerate WebPlane Mesh (Default Path) | WebPlane を既定の設定・保存先で作り直す |
| Tools > SpiderShader > SpiderWeb を lilToon に焼き込む… | 選んでいる巣のオブジェクトを lilToon に焼き込む確認画面を開く（lilToon が必要。[詳しく](SpiderWeb.md#巣を-liltoon-に焼き込む軽量化)） |
| MeshRenderer のインスペクタ右上の「⋮」 > SpiderWeb を lilToon に焼き込む… | 同じ確認画面を、その MeshRenderer を対象にして開く |

焼き込みは 2 種類あり、入口が違います。

- **蜘蛛の巣ドレープの模様の焼き込み**（表示に必須）: メニューではなく、マテリアルのインスペクタの「焼き込みの状態」欄から行います（[詳しく](SpiderWebDrape.md#焼き込み)）。
- **蜘蛛の巣を lilToon に焼き込む軽量化**（任意）: 上のメニュー・MeshRenderer の「⋮」メニューか、巣のマテリアルのインスペクタの「lilToon に焼き込む（軽量化）」欄から行います。
