# 地面転写（SpiderWebGroundProjector）

シェーダー名: `mecaota/SpiderWebGroundProjector`

[← README に戻る](../README.md) ｜ 関連: [蜘蛛の巣（SpiderWeb）](SpiderWeb.md)

## ひとことで

Unity 標準の **Projector コンポーネント**で、床に蜘蛛の巣などの画像を真上から投影するシェーダーです。「足元に落ちる丸い影（ブロブシャドウ）」と同じ仕組みです。

- 上を向いた面（床）にだけ映ります。壁や体の正面には映りません。
- 深度テクスチャを使わず、床かどうかを床のメッシュの向きで判定するので、VR の左右の目やミラーで映り方が食い違いません。
- 投影する画像（テクスチャ）は同梱していません。透明部分のある蜘蛛の巣の画像を用意してください。
- 試験的に入れたシェーダーです。専用のインスペクタ（色分けやプリセット）はなく、Unity 標準のインスペクタで表示されます。質感の継承にも対応していません。
- 対応環境: Unity Built-in Render Pipeline。

## こんなときに使う

- 巣の張られた場所の足元に、うっすら巣の模様を映したい
- プレイヤーに追従して、足元に巣の模様を出したい

## クイックスタート

1. 透明部分（アルファ）を含む蜘蛛の巣の画像を用意し、Import Settings で **Alpha Is Transparency** を ON（透明部分の縁に色がにじむのを防ぐ）、**Wrap Mode を Clamp**（投影範囲の外に画像が繰り返し映るのを防ぐ）にします。
2. マテリアルを作り、Shader を `mecaota/SpiderWebGroundProjector` にして、「投影テクスチャ」に画像を入れます。
3. 空の GameObject に **Projector** コンポーネントを付け、真下に向けます（Rotation X = 90）。床の上に固定しても、プレイヤーに追従するオブジェクトの子にしても構いません。
4. Projector の設定:
   - **Orthographic** を ON にし、**Orthographic Size** で投影する範囲を決めます。値は範囲の中心から端までの距離（m）で、Aspect Ratio が 1 なら一辺がその 2 倍の正方形に映ります。
   - **Near Clip Plane** 0.1、**Far Clip Plane** は床まで確実に届く距離（例: 5）。
   - **Material** に 2 のマテリアルを入れます。Projector ごとに別のマテリアルにしてください。
5. アバターに映したくないときは、Projector の **Ignore Layers** で Player・PlayerLocal などのレイヤーを除外します。

## しくみ（シェーダー初心者向け）

Projector は、自分の視野（直方体）に入ったメッシュを、指定したマテリアルでもう一度描きます。このシェーダーはその 2 回目の描画で、Projector から見た位置に応じて画像を貼ります。Web でいえば、床の上に半透明の画像をもう 1 枚重ねて描いているイメージです。

- 受ける面の向きは、メッシュが持っている法線（面の向きのデータ）で判定します。深度から推定する方式と違い、左右の目で結果が完全に一致します。
- 床と同じ面をもう一度描くので、ちらつき（Z ファイティング）を防ぐために少し手前へずらして描いています。

## インスペクタの項目

| 見出し | 表示名 | 内部名 | 既定値 | 説明 |
|---|---|---|---|---|
| Ground Web | 投影テクスチャ 蜘蛛の巣など | `_GroundTex` | 黒（透明） | 投影する画像。Tiling / Offset も使える |
| | テクスチャの色 | `_GroundColor` | (1,1,1,1) | 画像に掛ける色。a で全体の濃さ |
| Receiver Filter | 受ける面の法線Y下限 | `_NormalYMin` | 0.5 | 面の上向き度合い（法線の Y）がこの値から +0.1 にかけて徐々に映る。上げるほど水平な床だけに限る |
| | 投影範囲の縁フェード | `_EdgeFade` | 0.15 | 投影範囲の四角い縁をぼかす幅 |
| | 遠端フェード開始 0-1 | `_FarFadeStart` | 0.7 | Far Clip に向かって薄くし始める位置（0＝Near、1＝Far） |

## 注意・制約

- **上向きの面（床）専用**です。天井に映すには、シェーダーの判定を下向き用に改造する必要があります。
- Projector は視野に入ったメッシュをもう一度描くので、範囲を広げるほど描画が重くなります。範囲は必要最小限にしてください。
- [蜘蛛の巣（SpiderWeb）](SpiderWeb.md)・繭などのこのパッケージのシェーダーは Projector の投影を受けない設定（`IgnoreProjector`）なので、巣の上には映りません。
- 描画順は `Transparent` です。
