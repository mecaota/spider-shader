# ねばねばネット（SpiderGooSilkSheet）

シェーダー名: `mecaota/SpiderGooSilkSheet`

[← README に戻る](../README.md) ｜ 関連: [吐いた糸（SpiderThreadTrail）](SpiderThreadTrail.md) ／ [共通機能](CommonFeatures.md) ／ [Udon ギミック](UdonGimmicks.md)

## ひとことで

[吐いた糸](SpiderThreadTrail.md)の粘液モードの帯（太い束＋穴の空いた膜）を、すき間なく並べた**粘液のシート**を描くシェーダーです。シートを少しずつ回転・ずらしながら最大 8 層重ねるので、網というより「粘液がどろっと覆いかぶさった」見た目になります。

- 模様は事前に Editor で画像へ**焼き込み**ます。**焼き込むまでは何も表示されません。**
- 投げ網と同じ「体に覆いかぶさる変形」に対応しています（駆動する Udon は別途必要）。
- 対応環境: **PC 専用**（Texture2DArray・BC5/BC7 圧縮・9 パスを使うため）。Unity 2022.3、Built-in Render Pipeline。

## こんなときに使う

- 捕まえたプレイヤーに上から粘液のネットをかぶせる
- 板・球・円柱を粘液の膜で覆った見た目の置物

## クイックスタート

1. マテリアルを作り、Shader を `mecaota/SpiderGooSilkSheet` にします（この時点ではまだ何も表示されません）。
2. 紫の「蜘蛛糸の質感（継承）」欄で、継承元の吐いた糸マテリアルを選びます（選ばなければ標準の質感）。
3. マテリアルを WebPlane（[生成方法](SpiderWeb.md#webplane-メッシュの生成ツール)）や Unity 標準の Plane・Sphere などに入れます。UV・法線・接線を持つメッシュなら使えます。
4. インスペクタ下部の黄緑色の **「焼き込みの状態」** 欄を開き、**「焼き直す」** を押します。数秒で模様が表示されます。
5. 形（帯の幅・向き・束の形など）を変えたら、もう一度「焼き直す」を押します。色・ツヤ・層の枚数などは焼き直し不要です（下の表）。

## しくみ（シェーダー初心者向け）

1. **帯 1 本 = 吐いた糸の粘液**: 吐いた糸の粘液モードは、帯の中に太い束を並べ、束の間に穴の空いた膜を張る「距離場」で描かれています。この計算をそのまま使います。
2. **すき間なく並べる**: その帯を「帯の向き」に沿わせ、「帯の幅」ごとにすき間なく積みます。帯ごとに模様の位置をずらすので、同じ帯の繰り返しには見えません。
3. **焼く**: Editor でこの模様を 3 枚の画像（形状・補助・被覆率）に保存します。保存するのは完成した色ではなく「粘液までの距離」などの値です。そのため実行中も、吐いた糸と同じ丸い断面・ツヤ・輪郭線・透けで塗れ、光や視点の変化に反応します。Web でいえば、毎回重い計算をする代わりに結果をキャッシュしておき、表示時はキャッシュを読むだけにするイメージです。
4. **重ねて被せる**: 実行中は、各層が画像を少し回転・ずらして読み、重ねて描きます。1 層だと帯のすき間が筋になって残り、2 層でほぼ埋まり、3 層では穴だけが残る膜になります。

## 焼き込み

### 焼き直しが必要な項目・不要な項目

| 焼き直しが必要 | 焼き直し不要 |
|---|---|
| 帯の幅・帯の向き・帯に沿った長さ | 色・陰影・ツヤなど質感（「粘液感」を除く） |
| 帯の中の形（束の本数・太さ・並ぶ幅・蛇行・玉・融合・膜・穴） | 重ねる膜の枚数・全層の厚さ・接着・層ごとの回転 |
| 膜の外形の半径・模様のずれ | 層ごとの不透明度・層ごとの太さ |
| 揺らぎシード | 裏面の糸を隠す |
| 焼き込み設定（模様の枚数・解像度・圧縮・読取範囲の余白） | 接触追従の変形・体に覆いかぶさる変形 |
| 継承元の「粘液感」（`_GooAmount`） | |

- 「焼き込みの状態」欄には、マテリアルごとに「焼き込み済み（現在の形状・形式と一致）」か「未生成、または形状・生成形式が変わっています。焼き直してください。」が表示されます。
- 継承元の吐いた糸で「粘液感」を変えた場合も焼き直しが必要です（粘液感は形の太さを変えるため、焼いた時点の値で固定されます）。

### 「焼き直す」ボタンの動き

- 選択している複数のマテリアルをまとめて焼きます。
- 焼いた画像は **`Assets/mecaota/GooNet/Baked/`** に `（64 桁の英数字）-shape.asset` / `-detail.asset` / `-coverage.asset` の 3 ファイルとして保存されます。保存先は変更できません。
- 形と形式が同じマテリアルどうしは、同じ 3 ファイルを共有します。
- 既に同じものがあるときはボタンが「焼き直す（同じアセットを更新）」になり、上書きしても参照（GUID）は切れません。
- Ctrl+Z で取り消せます（Undo 名「粘液シートを焼き直す」）。

焼き込みが失敗するとき（Console にエラーが出ます）:

- Play 中・スクリプトのコンパイル中
- GPU が Texture2DArray・BC5/BC7 圧縮・浮動小数点の RenderTexture に対応していない
- 帯の幅・帯に沿った長さ・半径が 0 以下

### メモリの目安

| 設定 | 3 枚の画像の GPU メモリ |
|---|---|
| 1024・模様 3 枚・圧縮（既定） | 約 12 MiB |
| 512・模様 3 枚・圧縮 | 約 3 MiB |
| 1024・模様 3 枚・無圧縮 | 約 36 MiB |

焼いた画像は、CPU 側にも画素を残した状態で保存します（残さないと .asset に画素が書かれないため）。その分、実行中はメインメモリにも同じ量を持ちます。解像度を 1024 から 512 に下げても描画の速さはほとんど変わりません。

### 使われていない焼き込みの削除

焼き直すと、古い形の画像が `Assets/mecaota/GooNet/Baked` に残ります。「焼き込みの状態」欄の **「使われていない焼き込みを削除…」** を押すと、どのマテリアル・Prefab・シーンからも使われていない画像を OS のゴミ箱へ移します。

> 削除したあとに「焼き直す」を Ctrl+Z で取り消すと、ゴミ箱へ移した画像を参照して表示が崩れます。そのときはもう一度焼き直してください。

## インスペクタの項目

インスペクタの並び順で載せています。紫の「蜘蛛糸の質感（継承）」欄（21 項目）は [共通機能のページ](CommonFeatures.md#継承する-21-項目) を参照してください。

### 粘液の形・粘液の膜（共通）／吐いた糸の粘液の束（固有）

帯の中の形です。**吐いた糸と同じ名前・範囲・既定値**で、意味も同じです（[吐いた糸のページ](SpiderThreadTrail.md#粘液の形共通)を参照）。すべて焼き直しが必要です。

| カテゴリ | 項目 |
|---|---|
| 粘液の形（共通） | くびれと玉 `_GooBeads`（0.55）・玉の細かさ `_GooBeadFreq`（2.2）・融合の粘り `_GooMerge`（0.35） |
| 粘液の膜（共通） | 束の間の膜の量 `_GooWeb`（0.6）・穴の間隔 `_GooWebCell`（0.3）・穴の列数 `_GooWebRows`（2.5）・穴の開き具合 `_GooWebHole`（0.85） |
| 吐いた糸の粘液の束（固有） | 束の本数 `_GooStrands`（3）・束の太さ `_GooWidth`（0.24）・束の並ぶ幅 `_GooSpread`（0.6）・蛇行の振れ幅 `_GooWobble`（0.16）・蛇行の細かさ `_GooWobbleFreq`（0.7） |

吐いた糸にある「玉が流れる速さ」「尻尾ほど細く伸びる」はありません。

### 粘液シートの形（固有）

| 表示名 | 内部名 | 既定値 | 説明 |
|---|---|---|---|
| 膜の外形の半径 UV | `_WebRadius` | 0.5 | 膜の外形（円）の半径（UV）。0.71 で UV の正方形いっぱい。焼き直しが必要 |
| 粘液の帯の幅 UV | `_SheetBandWidth` | 0.12 | 帯 1 本の幅（UV）。広いほど穴が大きく膜らしい。焼き直しが必要 |
| 帯の向き 角度 | `_SheetRotation` | 17 | 帯の向き（度）。焼き直しが必要 |
| 帯に沿った長さ m/UV | `_SheetAlongScale` | 3 | 帯に沿った方向の UV 1 あたりの長さ（m）。玉・穴の細かさを吐いた糸と同じメートル単位にそろえる。焼き直しが必要 |
| 揺らぎシード | `_Seed` | 0 | ランダムの種。模様のほか、実行中の接着のまだら・太さのばらつき・ずれの向きにも使う。焼き直しが必要 |
| 裏面の糸を隠す | `_HideBackFibers` | OFF | ON で裏面を描かない |

### 粘液シートの焼き込み設定（固有）

すべて焼き直しが必要です。

| 表示名 | 内部名 | 既定値 | 説明 |
|---|---|---|---|
| 焼込: 模様の枚数 | `_BakedVariants` | 3 | 焼く模様の種類（1〜3）。層ごとに違う模様を割り当てる |
| 焼込: 解像度 | `_BakeResolution` | 1024 | 512 / 1024 / 2048 |
| 焼込: 無圧縮 / 圧縮 | `_BakeCompression` | 圧縮 | 圧縮は BC5＋BC7＋R8 |
| 焼込: 読取範囲の余白 UV | `_BakePadding` | 0.08 | 回転・ずらしても模様が途切れないよう、焼く範囲に足す余白 |

### 粘液シートの重なり（固有）

焼き直し不要です（「模様のずれ」だけは必要）。

| 表示名 | 内部名 | 既定値 | 説明 |
|---|---|---|---|
| 重ねる膜の枚数 | `_WebLayers` | 2 | 重ねる層の数（1〜8） |
| 浮遊部の全層の厚さ m | `_WebLayerDepth` | 0.06 | 層どうしが離れて浮いている所の、全層を合わせた厚さ |
| 接着部の全層の厚さ m | `_WebLayerContactDepth` | 0.008 | 層どうしがくっついている所の、全層を合わせた厚さ |
| 接着する割合の目安 | `_WebLayerAdhere` | 0.35 | 層どうしがくっつく所の広さの目安（膜の中央ほどくっつきやすい） |
| 接着の斑の細かさ UV毎 | `_WebLayerAdhereScale` | 4 | くっつく所のまだら模様の細かさ |
| 層ごとの回転 角度 | `_WebLayerTwist` | 8 | 1 層ごとに模様を回す角度（層番号 × 角度） |
| 模様のずれ上限 半径比 | `_WebLayerShift` | 0.08 | 2 層目以降の模様を、ランダムな向きにこの量（× 膜の半径）ずらす。**焼き直しが必要** |
| 層ごとの不透明度倍率 | `_WebLayerOpacity` | 0.95 | 外側の層ほど薄くする倍率（層番号ぶん掛け算） |
| 一番外の層の太さ倍率 | `_WebLayerWidthOuter` | 1 | 束の太さの倍率を、一番内側の層の 1 から一番外の層のこの値まで直線で変える |
| 層ごとの太さのばらつき | `_WebLayerWidthJitter` | 0 | 層ごとに束の太さをランダムに変える量（1 で 0.5〜2 倍） |

### 接触追従の変形・体に覆いかぶさる変形（固有）

[蜘蛛の巣](SpiderWeb.md)と同じ名前・意味です。項目の説明は [Udon ギミックのページ](UdonGimmicks.md) を参照してください。体に覆いかぶさる変形を使うときは、UV で網の位置を決めるので WebPlane のような 1 枚の平面メッシュに貼ります。

### 詳細設定

Render Queue・Enable GPU Instancing・Double Sided Global Illumination（Unity 標準の項目）です。

## 描画について

- 9 つのパスで描きます。一番内側の層の芯だけ奥行き（深度）を書くパス `DEPTHSOLID_L0` と、各層を塗るパス `FORWARD_L0`〜`FORWARD_L7` です。
  - 深度を書くのが一番内側だけでも、体の向こう側や折り返した膜が手前に透けて濁るのは防げます。深度パスを全部なくすと濁ります。
  - 使っていない層のパスは、頂点の段階で潰れて何も描きません。
- 遠くでは、細かい模様の代わりに被覆率の画像で描き、ちらつきを抑えます。
- 描画順は `Transparent` です。
- 体に被せた 1 枚あたりの追加の描画時間は、作者の環境（PC・1080p）で 2 層 約 0.1〜0.3 ms でした。VR は両目分で約 2 倍です。計測の詳細は [開発者向けノート](../README.md#作者のワールドwebbedworldでの使用例と経緯) にあります。

## 注意・制約

- PC 専用です。Quest 向けの代替はありません。
- 焼き込みには Editor のスクリプト（このパッケージの `Editor/` フォルダ）が必要です。
- 接触追従の変形・体に覆いかぶさる変形を使うときは、**Batching Static を OFF**、マテリアルの **GPU Instancing を OFF** にしてください（このシェーダーは静的バッチングを自動では止めません）。
- 補助画像を拡大した所でツヤのギザギザや圧縮の誤差が見えることがあります。VRChat 実機・VR・ミラーでの見え方は確認してから使ってください。
- 以前あった別のねばねばネット系シェーダーは撤去済みです。それらを使っていたマテリアルはピンク（Hidden/InternalErrorShader）になります。経緯は [開発者向けノート](../README.md#作者のワールドwebbedworldでの使用例と経緯) を参照してください。
