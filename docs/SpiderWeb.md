# 蜘蛛の巣（SpiderWeb）

シェーダー名: `mecaota/SpiderWeb`

[← README に戻る](../README.md) ｜ 関連: [共通機能（インスペクタ・質感の継承・プリセット）](CommonFeatures.md) ／ [Udon ギミック](UdonGimmicks.md)

## ひとことで

平面や球のメッシュに、**縦糸（放射状の支持糸）と横糸（渦巻き状の捕獲糸）でできた蜘蛛の巣**を描くシェーダーです。テクスチャは使わず、糸の配置・太さ・粘液の玉・すき間の膜をすべて計算で描くので、本数や半径を数値で自由に変えられます。

- 糸は常に粘液の糸として塗ります（色・ツヤ・陰影は蜘蛛糸から[継承](CommonFeatures.md#質感の継承)）。縦糸と横糸の粘液感は別々に決められます。
- 扇形の巣・木の幹に張り付く曲面の巣も描けます。
- Udon と組み合わせると、**触れた手足に巣が貼り付いて伸びる**（接触追従の変形）・**投げた網が体に覆いかぶさる**（体に覆いかぶさる変形）表現ができます。
- 対応環境: Unity Built-in Render Pipeline。PC で動作確認しています。Quest（Android）では未検証です。

## こんなときに使う

- 壁・木の間・天井に張られた蜘蛛の巣
- 足を踏み入れると足に絡みつく地面の巣（[SurfaceContactDeformer](UdonGimmicks.md#接触追従の変形surfacecontactdeformer) と組み合わせ）
- パーティクルで飛ばして体に当てる投げ網
- 遠くからは見えず、近づくと現れる巨大な空中の巣（近接表示）

## クイックスタート（平面の巣を 1 枚置く）

1. メニュー **Tools > SpiderShader > Generate WebPlane Mesh...** を開き、そのまま **Generate** を押します。`Assets/mecaota/models/WebPlane.asset`（1 m 四方・64×64 分割の平面）ができます。
2. 空の GameObject を作り、**MeshFilter** に `WebPlane`、**MeshRenderer** を追加します。平面は XZ 平面（上が +Y）なので、壁に貼るときは X を 90° 回転させます。
3. マテリアルを作って Shader を `mecaota/SpiderWeb` にし、MeshRenderer に入れます。
4. インスペクタ先頭の「プリセット」欄で用途に合うものを押します（例: **「蜘蛛の住処の巣」** は触れても形が変わらない据え置きの巣）。
5. 色やツヤを変えたいときは、紫の「蜘蛛糸の質感（継承）」欄で継承元の蜘蛛糸マテリアルを選びます。巣のマテリアルでは質感を直接編集できません（[理由](CommonFeatures.md#質感の継承)）。

> Unity 標準の Quad でも描けます（UV が 0〜1 の平面なら何でも可）。ただし接触追従の変形を使うときは、細かく分割された WebPlane が必要です。

## しくみ（シェーダー初心者向け）

1. **距離場で糸を描く**: ピクセルごとに「一番近い縦糸までの距離」「一番近い横糸までの距離」を計算し、糸の太さより近ければ糸として塗ります。
2. **縦糸**はハブ（中心結節点）からの放射線です。角度を本数で等分し、糸ごとにランダムな角度のずれ（揺らぎ）を足します。
3. **横糸**は同心円で、縦糸と縦糸の間で中心側へ垂れ下がります。区間ごとに垂れ方を変えても、縦糸の上では必ずつながるように計算しているので、横糸が途中で切れません。
4. **粘液の融合**: 縦糸と横糸の距離を smooth-min（なめらかな最小値）で合成すると、交点が水かき状に埋まり、粘りが溜まったように見えます。すき間の角には、場所ごとにまだらな量の膜を張ります。
5. **塗り**: 糸の断面を丸い棒とみなして、トゥーン陰影・ハイライトの筋・輪郭線を付けます。蜘蛛糸・繭と同じ処理（`SpiderGoo_Shading.cginc`）なので、質感をそろえると見た目がつながります。
6. **模様は UV に貼りつく**ので、メッシュを曲げたり頂点を動かしたりしても糸は面に沿って伸びます（テクスチャを貼った布を引っぱるのと同じ）。

### 縦糸と横糸の粘液感（`_SpokeGoo` / `_RingGoo`）

実物の円網は、横糸（捕獲糸）だけが粘着し、縦糸（支持糸）は乾いています。この違いを 2 つの値で表します。

| 設定 | 見え方 | 向いている巣 |
|---|---|---|
| 縦糸 1・横糸 1 | 縦横とも粘液。すき間に膜が張る | 飛ばした網・投げ網 |
| 縦糸 0・横糸 1 | 縦糸は太さ一定のまっすぐな乾いた糸、横糸だけ粘液 | 固定設置の巣（実物の円網と同じ） |
| 縦糸 0・横糸 0 | 乾いた細い糸だけ（交点はつながる） | 古い巣・目印 |

- 粘液感が 1 未満の糸は、太さの揺らぎが一定幅に近づき、粘液の太り・玉・ツヤ・透けが弱まります。
- すき間の膜は、縦糸と横糸の**両方**が粘液のときだけ張ります（小さい方の値に比例）。
- 交点は設定に関係なく 1 つの距離場で融合するので、どの組み合わせでも糸はつながります。

## インスペクタの項目

インスペクタの並び順で載せています。紫の「蜘蛛糸の質感（継承）」欄（21 項目）は [共通機能のページ](CommonFeatures.md#継承する-21-項目) を参照してください。

### 糸のデザイン（共通）

| 表示名 | 内部名 | 既定値 | 説明 |
|---|---|---|---|
| 太さの乱雑性 | `_ThreadJitter` | 0.3 | 糸ごとにランダムに細く・太くする量 |
| 幅の揺らぎ | `_ThreadFuzz` | 0.2 | 糸の長さ方向の太さのうねり |
| 揺らぎの細かさ | `_ThreadFuzzScale` | 8 | うねりの細かさ |

### 揺れアニメ（共通）

横糸（緯糸）だけを揺らします。縦糸・ハブ・縦横の接続点は動きません。横糸の並びが入れ替わらないよう、揺れ幅は横糸の間隔の 6% までに自動で抑えられます。

| 表示名 | 内部名 | 既定値 | 説明 |
|---|---|---|---|
| 緯糸の揺れ有効 | `_SwayAnimEnable` | OFF | ON で横糸が揺れる |
| 揺れ幅 | `_SwayAnimAmount` | 0.012 | 揺れ幅（UV） |
| 揺れの速さ | `_SwayAnimSpeed` | 1.5 | 揺れの速さ |
| 端の固定幅 0で固定なし | `_SwayAnimAnchor` | 0.15 | メッシュの端に近い所を揺らさない幅 |

> 接触追従の変形とは別の処理なので、手足が触れている所も揺れは止まりません。

### 粘液の形（共通）

| 表示名 | 内部名 | 既定値 | 説明 |
|---|---|---|---|
| 粘液の太さ倍率 | `_GooThick` | 1.6 | 糸の太さに掛ける倍率（縦糸・横糸それぞれの粘液感の分だけ効く） |
| 粘着玉の大きさ | `_GooBeads` | 0.5 | 糊の玉の大きさ。横糸に強く、縦糸には控えめに付く |
| 粘着玉の細かさ UV毎 | `_GooBeadFreq` | 30 | UV 1 あたりの玉の数 |

### 粘液の膜（共通）

| 表示名 | 内部名 | 既定値 | 説明 |
|---|---|---|---|
| すき間を埋める膜 | `_GooWebFill` | 0.35 | すき間の角を埋める膜の量。0 で交点の粘着だまりだけ |
| 膜のまだらの細かさ UV毎 | `_GooWebScale` | 7 | 膜のまだら模様の細かさ |

### 蜘蛛の巣カスタマイズ(個別)（固有）

巣の形です。メッシュごとに決まる値なので、プリセット適用時に「巣の形・配置（個別）も上書きする」を OFF にすると今の値が残ります。

| 表示名 | 内部名 | 既定値 | 説明 |
|---|---|---|---|
| 中心結節点オフセット X | `_HubOffsetX` | 0 | ハブ（糸が集まる中心）を横にずらす。円形では巣の半径に対する割合、扇形では -1＝UV の左端、+1＝右端 |
| 中心結節点オフセット Y | `_HubOffsetY` | 0 | 同じく縦方向（扇形では -1＝下端、+1＝上端） |
| 巣の半径 | `_WebRadius` | 0.45 | 外周の半径（UV）。0.5 で UV の正方形に内接 |
| 糸の太さ | `_Thickness` | 0.0025 | 糸の太さ（UV） |
| 縦糸の本数 放射 | `_RadialCount` | 14 | 放射状の縦糸の本数（3〜36） |
| 横糸の本数 渦巻 | `_RingCount` | 9 | 同心円の横糸の本数（1〜30） |
| 垂れ下がり具合 | `_Sag` | 0.4 | 横糸が縦糸の間で中心側へ垂れる量 |
| 縦糸をメッシュ端まで延長 | `_SpokeExtend` | OFF | ON で縦糸を外周で止めず、メッシュの端まで伸ばす（係留糸） |
| 揺らぎの強さ | `_Irregular` | 0.35 | 縦糸の角度・横糸の垂れ方のランダムさ |
| 揺らぎシード | `_Seed` | 0 | ランダムの種。巣ごとに変えると別の形になる |
| 裏面の糸を隠す | `_HideBackFibers` | OFF | ON で裏面を描かない。球などで奥の糸が透けるのを防ぐ |

ハブをずらしても、外周と縦糸の終端（メッシュの端）は動きません。実物の巣のように、ハブに近い側は横糸の間隔が密に、遠い側は疎になります。

### 扇形の巣（固有）

| 表示名 | 内部名 | 既定値 | 説明 |
|---|---|---|---|
| 扇形の巣 | `_FanEnable` | OFF | ON で扇形にする |
| 扇の開き角度 | `_FanAngle` | 90 | 扇の開き（15〜330 度） |
| 扇の向き | `_FanRotation` | 45 | 扇の向き（度）。0 度＝UV の +X、90 度＝UV の +Y（WebPlane ではローカル +X と +Z） |
| 外周をメッシュUV2から取得 | `_FanMeshRim` | OFF | ON で外周を UV の縁ではなくメッシュの UV2.x から取る（曲面の巣用） |

扇形の使い方:

1. 「扇形の巣」を ON にし、ハブ（中心結節点オフセット）を扇の要の位置へ動かします。例: 左下の角を要にするなら X・Y とも -0.94 前後。
2. 「扇の開き角度」と「扇の向き」で扇の範囲を決めます。
3. 横糸は扇の外周（メッシュの端）まで並び、端に沿って止まります。「巣の半径」はそれより内側で止めたいときの上限なので、端まで張るときは最大の 1.5 にします。
4. 支持糸だけを端まで伸ばしたいときは「縦糸をメッシュ端まで延長」を ON にします。

### 曲面の巣（木の幹に張り付く扇形など）

「外周をメッシュUV2から取得」を ON にすると、曲がったメッシュにも扇形の巣を貼れます。メッシュは自分で用意する必要があります（このパッケージに生成ツールは含まれません）。

- **UV0** は曲面の展開図にします（UV の長さが曲面上の長さにほぼ比例するように）。こうすると糸の太さがどこでもほぼ同じになります。
- **UV2.x** に「ハブから外周までの UV 距離」を入れます。横糸はそこで止まります。
- 標準プリセット「木の幹の扇形の巣」がこの用途の設定例です。

### 粘着糸の質感（固有）

| 表示名 | 内部名 | 既定値 | 説明 |
|---|---|---|---|
| 支持糸の太さ倍率 | `_SpokeWidth` | 1 | 縦糸の太さの倍率 |
| 横糸の太さ倍率 | `_RingWidth` | 1 | 横糸の太さの倍率 |
| 自然な太細の偏り | `_Organic` | 0 | 1 で、太さが常に正のなめらかな揺らぎになる。0 は従来の太さ計算 |
| 交点の粘着だまり | `_JunctionSize` | 0 | 大きくすると交点の粘りが膜のように広がる |
| 縦糸の粘液感 0で乾いた直線 | `_SpokeGoo` | 1 | 縦糸の粘液感（上の「縦糸と横糸の粘液感」） |
| 横糸の粘液感 | `_RingGoo` | 1 | 横糸の粘液感 |

### 接触追従の変形（固有）

手足が触れた場所を伸ばしたり凹ませたりします。Udon の [SurfaceContactDeformer](UdonGimmicks.md#接触追従の変形surfacecontactdeformer) と組で使います。項目の説明は [Udon ギミックのページ](UdonGimmicks.md#シェーダー側の設定接触追従の変形) にまとめています（`_PullRadius` の既定値は 0.5）。

### 体に覆いかぶさる変形（固有）

投げつけた網が体の形に沿ってかぶさる変形です。駆動する Udon（`SpiderWebDrapeDriver`）と組で使います。項目の説明と駆動スクリプトの使い方は [Udon ギミックのページ](UdonGimmicks.md#体に覆いかぶさる変形drape) を参照してください。

### 近接表示（巨大な空中の巣）（固有）

カメラから遠い所を消し、近づくと巣が現れるようにします。空中に張った巨大な巣を、近くに来た人にだけ見せたいときに使います。

| 表示名 | 内部名 | 既定値 | 説明 |
|---|---|---|---|
| 近接表示 有効 | `_RevealEnable` | OFF | ON で近接表示（シェーダーキーワード `SW_REVEAL`） |
| 完全に見える距離 m | `_RevealNear` | 3.5 | カメラからこの距離までは完全に見える |
| 見えなくなる距離 m | `_RevealFar` | 8 | この距離より遠い所は見えない |
| 境界のばらつき m | `_RevealNoise` | 1.5 | 見える・見えないの境界をランダムにずらす幅 |
| ばらつきの細かさ 1/m | `_RevealNoiseScale` | 0.6 | ばらつきの細かさ |
| 下端 ワールドY 左,右 Udonが設定 | `_ClipLine` | (-100000,-100000,0,0) | 巣の下端を切る高さ。Udon が Renderer ごとに設定する値で、既定のままなら切らない |

- 距離の判定はカメラ位置（VR では両目の中点）で行うので、左右の目で見え方が食い違いません。
- `_ClipLine` を設定する Udon はこのパッケージに含まれていません。設定しなくても距離による表示切り替えだけで動きます。

### 詳細設定

Render Queue・Enable GPU Instancing・Double Sided Global Illumination（Unity 標準の項目）です。接触追従の変形を使うときは GPU Instancing を OFF にしてください。

## 標準プリセット

インスペクタの「プリセット」欄から使えます。巣のプリセットは**質感（色・ツヤ）を含みません**。見た目の色は継承元の蜘蛛糸で決まります。

| カテゴリ | プリセット | 使いどころ |
|---|---|---|
| 投げ網（縦糸も粘液） | 投げ網（基本） | パーティクルで飛ばす網 |
| | 張り付く投げ網 | 体に張り付く網（SurfaceContactDeformer と組で使う） |
| | 射出網 | 弾として体に当てる網（SurfaceContactDeformer と組で使う） |
| | 覆いかぶさる捕獲網 | 体を包む捕獲網（体に覆いかぶさる変形を駆動する Udon と組で使う） |
| | 漂う網玉 | 空中を漂う網の玉（接触追従の変形が ON） |
| 設置された巣（縦糸は乾いた直線） | 設置された巣（張り付く） | 平面・球のメッシュに張る巣（SurfaceContactDeformer と組で使う） |
| | 木の幹の扇形の巣 | 木の幹から地面へ広がる扇形の巣（外周を UV2 に持つ曲面メッシュ用） |
| | 蜘蛛の住処の巣 | 触れても形が変わらない据え置きの巣 |
| 目印 | 地面のかすかな巣（エリア目印） | 地面に置くエリアの目印。うっすら見せるには、継承元の「粘液感」を 0.2・「不透明度」を 0.35 くらいにし、色を暗めにする |

> 標準プリセットは、体に覆いかぶさる変形の後から追加された項目（巻きつく周回数・姿勢追従など）と近接表示の値を含みません。適用してもそれらは今の値のまま残ります。

## 大きな巣を作るときの目安

10〜18 m の大きな WebPlane で接触追従の変形を使うと、64 分割では接触部が角張ります。**Generate WebPlane Mesh** で分割数（Segments）を 128 にしたメッシュ（16,641 頂点）を使ってください。頂点数が約 4 倍になるので、大きい巣だけに使います。

| 項目 | 目安 | 意味 |
|---|---|---|
| 引っ張り半径 | 0.9 m | 変形が周りに伝わる距離 |
| 千切れ開始距離 / フェード幅 | 0.7 m / 0.15 m | 0.85 m で戻り切る。SurfaceContactDeformer の Auto Release Distance を 0.85 m にすると一致する |

## WebPlane メッシュの生成ツール

| メニュー | 内容 |
|---|---|
| Tools > SpiderShader > Generate WebPlane Mesh... | 設定を選んで生成する |
| Tools > SpiderShader > Regenerate WebPlane Mesh (Default Path) | 既定の設定・保存先のまま作り直す |

| 設定 | 既定値 | 説明 |
|---|---|---|
| Segments | 64 | 1 辺の分割数（1〜255） |
| Size | 1 | 1 辺の長さ（m） |
| Bounds Up | 2 | 法線方向（±Y）へ描画範囲（バウンズ）を広げる量 |
| Bounds Lateral | 0.5 | 横方向へバウンズを広げる量（片側） |
| Asset Path | `Assets/mecaota/models/WebPlane.asset` | 保存先 |

- 生成されるのは XZ 平面（法線 +Y）で、UV は 0〜1（u＝+X、v＝+Z、中央がハブの既定位置）です。
- 頂点シェーダーで動かす分はバウンズに含まれないので、あらかじめ広げてあります。足を 2 m 以上持ち上げるような使い方では、Bounds Up を増やして作り直してください。
- 既存のアセットを作り直すときは GUID を保つので、参照は切れません。

## 巣を lilToon に焼き込む（軽量化）

巣の模様（縦糸・横糸・粘液）をテクスチャ（画像）に焼き、そのレンダラーのマテリアルを **lilToon** のマテリアルに差し替える Editor の機能です。巣を軽くしたいときに使います（使わなくても構いません）。

- このシェーダーは、画面の 1 画素ごとに「一番近い糸までの距離」などを計算して巣を描いています。焼いた巣は画像を 1 回読むだけなので、画面を大きく占める巣ほど軽くなります。作者の環境（PC・1080p）では、画面を大きく占める巣 1 枚の描画時間が 0.7〜1.0 ms から 0.06〜0.34 ms に減りました（計測の詳細は [開発者向けノート](../CONTRIBUTING.md) の「作者のワールド」の節）。
- そのかわり、シェーダーの動き（揺れ・触れたときの変形・近接表示・Udon の演出など）は失われます。
- **焼く前に、そのレンダラーで失われる機能と注意事項の一覧が出ます。同意したときだけ焼きます。**
- 元の設定はレンダラーに付く控えのコンポーネントに残るので、いつでも元に戻せます。

> lilToon（`jp.lilxyzw.liltoon`、2.3.x で確認）を入れたプロジェクトでだけ使えます。lilToon はこのパッケージの必須の依存ではありません。lilToon が無くてもコンパイルは通り、焼き込みのボタンが押せなくなって理由が表示されます。

### 使い方

1. シーンで巣のオブジェクト（MeshRenderer）を選び、次のどれかで確認画面を開きます。
   - メニュー **Tools > SpiderShader > SpiderWeb を lilToon に焼き込む…**
   - MeshRenderer のインスペクタ右上の「⋮」メニュー → **SpiderWeb を lilToon に焼き込む…**
   - 巣のマテリアルのインスペクタの「**lilToon に焼き込む（軽量化）**」欄のボタン（マテリアル単体では焼きません。シーンで選んでいる、そのマテリアルを使うレンダラーが対象です）
2. 確認画面で、解像度・モードなどを選びます（下の表）。
3. 「**失われる機能**」と「**注意事項**」を読みます。【重大】【注意】【参考】に分けて出ます。
4. 「**上記を理解し、焼き込みに同意します**」にチェックを入れると、「**焼き込む**」が押せるようになります。
   - 設定や対象を変えると、確認内容が変わるのでチェックは外れます。見直しは、設定を変えてから少しあとにまとめて行います。
5. 「焼き込む」を押すと、次のようになります。
   - 保存先にテクスチャ（PNG）と lilToon のマテリアルができます。
   - レンダラーのマテリアルが lilToon のマテリアルに差し替わり、レンダラーの影が切られます。
   - レンダラーに、控えのコンポーネント **SpiderWebBakeBackup** が付きます。
   - Undo（Ctrl+Z）1 回で、差し替えと控えを取り消せます（作ったテクスチャとマテリアルのアセットは残ります）。
6. 元に戻すときは、SpiderWebBakeBackup のインスペクタの「**元に戻す…**」を押します。
   - 焼く前のマテリアルとレンダラーの設定（影など）に戻り、控えのコンポーネントは外れます。これも Undo 1 回で取り消せます。
   - **焼いたテクスチャとマテリアルは消しません**（要らなければご自身で削除してください）。

確認画面の設定:

| 設定 | 既定値 | 説明 |
|---|---|---|
| 解像度（長い辺） | 2048 | 1024 / 2048 / 4096。短い辺は UV の縦横比に合わせて自動で決まる。糸 1 本が 2 テクセル未満になると注意が出る |
| モード | Cutout ＋ alpha to coverage | Cutout ＋ alpha to coverage か、Transparent（半透明） |
| Cutout のしきい値 | 0.5 | 0.05〜0.95。これより濃い所を糸として残す（Cutout のとき） |
| 保存先（空なら自動） | 空 | 空なら `Assets/mecaota/BakedWebs/<シーン名>/`。ファイル名は `<オブジェクト名>_<確認内容の指紋 8 桁>`（巣のスロットが複数あるときは、後ろに `_s<スロット番号>` が付く） |

### 対象と対象外

**対象**: `mecaota/SpiderWeb` のマテリアルを使っている、シーンの中の **MeshRenderer**（WebPlane・Quad などの平面の巣、球の巣、扇形・曲面のメッシュの巣など）。マテリアルが複数あるときは、巣のスロットだけを焼きます。

**対象外**（確認画面に理由が出て、焼けません）:

- パーティクルで飛ばす巣（ParticleSystemRenderer）と SkinnedMeshRenderer。形が実行時に変わるので、1 枚の画像に焼けません。
- 蜘蛛糸・繭・繭デカール・蜘蛛の巣ドレープのマテリアル。
- 体に覆いかぶさる網（`_DrapeEnable` が ON のもの）と、ワールド側で「焼けない」と登録したスクリプト（[API](#apiスクリプトから使うとき) の `RegisterKnownScript`）が参照しているもの。焼くと体への巻き付きが無くなり、網を動かす Udon がマテリアルの値を読んでいるとエラーログが出るためです。
- もう焼き込んであるレンダラー。焼き直すときは、先に「元に戻す…」で戻します。
- Project の prefab アセットの中のレンダラーと、Prefab Mode の中のレンダラー。prefab 本体を書き換えると、使っている全部のシーンに波及するためです。シーンに置いたインスタンスなら焼けます。
- Play 中。

### 失われる機能

確認画面には、そのレンダラーに当てはまるものだけが出ます。

| 項目 | 出る条件 | 重さ |
|---|---|---|
| 揺れ（横糸の揺れアニメ） | 「緯糸の揺れ有効」（`_SwayAnimEnable`）が ON | 注意 |
| 触れたときの変形 | 「接触追従の変形」（`_PullEnable`）が ON | 注意 |
| 近接表示のフェード | 「近接表示 有効」（`_RevealEnable`・`SW_REVEAL`）が ON。近づくと少しずつ現れるフェードと、下端の切り取り（`_ClipLine`）が無くなり、距離に関係なく全体が見える | 重大 |
| 見る角度・光の向きで動く艶・リム・陰影 | ツヤ・リム・シーン光の反映度のどれかが 0 でない | 注意 |
| 質感の継承 | 継承元の蜘蛛糸とつながっている。あとで継承元を変えても、焼いた巣は変わらない | 注意 |
| 半透明（Cutout のとき） | 不透明度が 1 未満か、中心の透けがある | 注意 |
| 糸がほとんど見えなくなる | 不透明度の上限が、しきい値の近くか、それより低い（うっすら見せる目印の巣など） | 重大 |
| スクリプトが操作している効果 | このレンダラーを参照しているスクリプトがある（下記） | 重大 / 注意 / 参考 |
| アニメーションがマテリアルの値を動かしている | 親の Animator / Animation のクリップに `material.*` の値がある | 重大 |

スクリプトの参照は、次のように調べます。

- シーンの中のすべてのスクリプトの欄を（配列の中まで）調べ、このレンダラーか、その GameObject を参照しているものを探します。同じオブジェクトのスクリプトで Renderer の欄が空のもの（実行時に `GetComponent<Renderer>()` でこのレンダラーを使うもの）も含めます。
- このパッケージの [SurfaceContactDeformer](UdonGimmicks.md#接触追従の変形surfacecontactdeformer) は、個別の説明を【重大】で出します。`matchFanShape` が ON なら、扇形の捕獲範囲が平面全体に変わる副作用も出します。
- ワールド側のスクリプトは、[API](#apiスクリプトから使うとき) の `RegisterKnownScript` で名前を登録すると、個別の説明を【重大】で出します（焼けないものとして登録することもできます）。
- それ以外のスクリプトは、レンダラーを参照していれば【注意】、GameObject だけなら【参考】として出します。実行時にマテリアルの値を読んだり、MaterialPropertyBlock で変えたりしているスクリプトは、焼いたあと効かなくなります。
- 調べるのに時間がかかるので、結果はレンダラーごとに覚えておきます。階層が変わったとき・Undo/Redo のときに捨て、焼く直前には必ず調べ直します。

注意事項も同じ画面に出ます。

- 描画順の変化。Cutout は 2450 になって深度を書くので、繭デカール（CocoonDecal）ののりが巣の上に塗られることがあります。Transparent は 3000 で、深度を書きません。半透明の巣・繭・糸との前後関係が変わることがあります。
- 影。レンダラーの影を切ります（元の巣も影を落としていません。元の値は控えに残ります）。
- 描画のパス。基本のパスは 2 回から 1 回に減ります。ただし lilToon は、ポイントライト・スポットライトが当たると ForwardAdd のパスが増えます。
- テクスチャの容量（BC7・ミップ込み）と、糸 1 本のテクセル数。陰影の向き（焼くときの太陽）。
- 遠くの糸と MSAA。1 を超える明るさ（HDR）は 1 で切られること。
- 共有マテリアル（このレンダラーだけを差し替え、同じマテリアルを使う他のレンダラーは変わらない）、prefab のインスタンスでの上書き、巣を作るエディター拡張を実行し直すと戻ることがあること。
- 実行時に Udon が MaterialPropertyBlock で変える値は焼けないこと、焼く UV の範囲、保存先、lilToon が必要なこと。

### 焼き方の要点（シェーダー初心者向け）

- **UV の平面に広げて描く**: 巣のメッシュを「頂点の位置 = UV」にして、テクスチャと同じ大きさの画面に描きます（`Editor/Shaders/SpiderWebBaker.shader`）。1 画素がテクスチャの 1 テクセルになります。
  - 扇形の曲面の巣の UV2（外周までの距離）や、0〜1 をはみ出す UV もそのまま扱えます。
  - UV の範囲は実際のメッシュから測り、lilToon のタイリング・オフセット（`_MainTex_ST`）で合わせます。
- **巣と同じ式で描く**: 模様の計算は、巣のシェーダーと同じ `Runtime/CGINC/SpiderWeb_Core.cginc` を使います。焼き込み用のシェーダーは `SW_BAKE` を定義してから読み込み、視線を「面を正面から見る」向きに、光を「焼くときのシーンの太陽」の向きに置き換えます。
- **焼く色**: 見る向きに依らない色です。糸の丸い断面のトゥーン陰影・ハイライト・リム・輪郭線を、焼くときのシーンの太陽（`RenderSettings.sun`。無ければいちばん明るい Directional Light、それも無ければ真上）の向きで照らして焼きます。
  - 光の色と明るさは焼かず、lilToon のライティングに任せます（`_AsUnlit` = 1 − シーン光の反映度。明るさの下限 0.25・上限 1.35 は元の巣と同じ）。lilToon の主光源は面の向きで暗くならないので、太陽の当たらない側は元の巣より少し明るく見えます。
  - 揺れ・接触の変形は止めた状態で、編集時のマテリアルの値で焼きます。
- **色の空間**: 色は Linear で計算し、sRGB の 8bit の PNG に保存します。Properties の無い焼き込み用シェーダーには Unity が色を Linear に直して渡さないので、C# で直してから渡しています。
- **縁のにじみ止め**: 糸の無いテクセルの色を、いちばん近い糸の色で埋めます（ダイレーション。不透明度は 0 のまま）。ミップやテクスチャの補間で、透明な所の黒が糸の縁へにじまないようにするためです。
- **遠くで糸が消えないミップ**: 遠くでは小さいミップ段（縮小した画像）が使われます。ふつうに平均すると細い糸の不透明度が薄まり、しきい値を下回って糸が消えます。
  - そこで、テクスチャの取り込み設定 **Mip Maps Preserve Coverage** で、「しきい値を超える画素の割合」を各段で保ちます（しきい値は Cutout のしきい値、Transparent では 0.5）。
  - 圧縮（BC7）後の各段の割合を GPU で実測し、控えのインスペクタに表として出します。
- **lilToon の設定**: Cutout は `Hidden/lilToonCutout`（描画順 2450・alpha to coverage）、Transparent は `Hidden/lilToonTransparent`（描画順 3000・深度を書かない）です。
  - 両面を描きます。元の巣で「裏面の糸を隠す」が ON なら、裏面を描きません。
  - 影・リム・マットキャップ・反射・発光は切ります（テクスチャに焼いてあるため）。
- **プラットフォーム**: テクスチャの圧縮は、Standalone（PC）を BC7 に上書きし、ほかは既定（CompressedHQ）のままです。Android（Quest）向けの設定は付けていません（このパッケージは PC 向けワールドを想定しているため）。

### 控えのコンポーネント（SpiderWebBakeBackup）

焼いたレンダラーに自動で付く、エディター専用のコンポーネントです（Add Component の一覧には出ません）。

**持つもの**

- 焼く前の `sharedMaterials`（参照）と、差し替えたマテリアルの全部の値の写し（シェーダー名・描画順・キーワード・全プロパティ）。元のアセットが消えても、同じ値のマテリアルを作り直せます。Material Variant は、親から順に重ねた（実際に効いている）値を持ちます。
- 焼き込みで変えたレンダラーの設定（影など）。prefab のインスタンスなら、焼く前から上書きだった値の一覧も持ちます。
- 焼き込みの設定、各ミップ段の被覆率、作ったアセットの場所、同意した注意事項。

**Play とビルドに影響しません**

- Unity のメッセージ関数（Awake / Update など）もメソッドも持たず、値を持っているだけです。
- VRChat SDK の「エディター専用」の印（`VRC.SDKBase.IEditorOnly`）と `HideFlags.DontSaveInBuild` を付けています。さらにワールドのビルドでは、`Editor/SpiderWebBakeBuildStrip.cs` がシーンから取り除きます（Play に入るときは何もしません）。
- UdonSharp のコンパイルからは見えません（`#if !COMPILER_UDONSHARP`）。

**元に戻すとき**

- 元のマテリアルのアセットが消えていたら、控えの値から作り直し、焼いたフォルダの `Restored/` に保存します。参照だけ切れていて、同じ GUID のアセットがあるときはそれを使います。
- 元のマテリアルが焼いたあとで編集されていたら、違いを一覧にして、「今の元のマテリアルで戻す」か「控えの値で作り直して戻す」かを選べます。違いはインスペクタの「変わったところ」にも出ます。
- 作り直したマテリアルは、元が Material Variant でも親を持たない普通のマテリアルになります（値は同じ）。
- prefab のインスタンスでは、焼く前に上書きでなかったレンダラーの値を prefab の値へ戻します（上書きを残しません）。ただし、控えの値から作り直したマテリアルのスロットは、prefab の上書きとして残します（prefab の値へ戻すと、作り直したマテリアルが使われなくなるため）。元のマテリアル（同じ GUID のアセットで見つけ直したものも含む）を使ったスロットは、prefab の値と同じなので上書きを残しません。

### API（スクリプトから使うとき）

| API | 内容 |
|---|---|
| `SpiderWebLilToonBaker.Analyze(renderer, settings)` | 焼けるか、失われる機能、注意事項を調べる（何も変えない） |
| `SpiderWebLilToonBaker.Bake(renderer, settings, consent)` | 焼く。同意の印（`SpiderWebBakeConsent`）が無いとき、確認したあとで対象・設定・マテリアルの値・確認内容が変わったときは、何もせずに例外で断る。同意の印は確認画面だけが作れる（画面を通さずに焼けないようにするため） |
| `SpiderWebLilToonBaker.DiffOriginals(backup)` | 元のマテリアルが焼いたあとで変わったところを調べる |
| `SpiderWebLilToonBaker.Revert(backup, restoreFolder, mode)` | 控えから元に戻す。`mode` は `UseOriginal`（既定）か `RecreateFromSnapshot`。`restoreFolder`（作り直したマテリアルの保存先）は空なら焼いたフォルダの `Restored/`。指定するときは `Assets/` の下（`..` を含まない）で、違反なら何も変えずに例外で断る |
| `SpiderWebLilToonBaker.RegisterKnownScript(scriptName, detail, blocksBake)` | ワールド側のスクリプトを登録する。焼く巣をそのスクリプトが参照していると、確認画面に `detail` を【重大】で出す。`blocksBake` が true なら、焼けない理由として出して断る |

`RegisterKnownScript` は、ワールド側の Editor 用スクリプト（`Editor` フォルダの中）から呼びます。例:

```csharp
using UnityEditor;

static class MyWorldWebBakeRegistration
{
    [InitializeOnLoadMethod]
    static void Register()
    {
        // 巣が崩れて再生するときのフェードを、Udon が MaterialPropertyBlock で動かしている
        SpiderWebLilToonBaker.RegisterKnownScript("MyWebTrap",
            "巣が崩れて再生するときのフェードが効かなくなり、巣はパッと消えたり現れたりします。");
        // 体に巻き付ける網。焼くと網として働かないので、焼けないようにする
        SpiderWebLilToonBaker.RegisterKnownScript("MyNetThrower",
            "体に巻き付ける網は焼けません（巻き付きが無くなり、Udon がエラーログを出します）。", blocksBake: true);
    }
}
```

- `scriptName` はクラス名です。UdonSharp のスクリプトは元のクラス名で照らし合わせます（裏側の UdonBehaviour も同じ名前で見つかります）。
- 説明にスクリプトの設定値を入れたいときは、`detail` の代わりに `Func<Component[], string>` を渡す版を使います。参照しているコンポーネントが渡されます。null か空文字を返すと、登録していないときと同じ説明になります。ただし `blocksBake` が true のときは別で、説明が空でも「焼けません」という汎用の文で必ず断ります。
- 登録はスクリプトの再読み込みで消えるので、`[InitializeOnLoadMethod]` で毎回登録します。同じ名前を登録し直すと上書きします。

### 注意

- 焼いたあとで巣のマテリアルや継承元の質感を変えても、焼いた巣には反映されません。焼き直すときは、控えの「元に戻す…」で戻してから、もう一度焼きます。
- 巣を作ったり設定したりするエディター拡張（ワールド側のビルダーなど）を実行し直すと、マテリアルが元に戻ることがあります（控えは残ります）。そのときは焼き直すか、「元に戻す…」で控えを整理します。
- alpha to coverage の縁のなめらかさは、アンチエイリアス（MSAA）の設定によります。MSAA なしでは縁がギザギザになります。
- lilToon は 2.3.x で確認しています。lilToon のマテリアルの設定は、lilToon の内部の関数（`lilMaterialUtils.SetupMaterialWithRenderingMode`。無ければ `lilToonInspector` の公開版）をリフレクションで呼んでいます。lilToon の版が変わって関数やプロパティが見つからないときは、理由が表示されて焼けません。
- prefab のインスタンスで焼いたり戻したりすると、UdonSharp が U# の表側に `serializationData.Prefab` の上書きを付けることがあります。これは UdonSharp の仕様です。

## 描画について

- 描画順は `Transparent` です。蜘蛛糸（`Transparent-10`）より後に描きます（理由は [蜘蛛糸のページ](SpiderSilk.md#描画順とステンシル)）。
- 2 つのパスで描きます。Pass 0 `DEPTHSOLID` は不透明度 0.5 以上の芯だけ深度を書き、Pass 1 `FORWARD` で全体を塗ります。半透明でも、濃い糸の前後関係が保たれます。
- Projector の投影を受けません（`IgnoreProjector`）。
- ポイントライト・スポットライトは効きません。影も落としません。
- [lilToon に焼き込んだ](#巣を-liltoon-に焼き込む軽量化)巣は、このシェーダーではなく lilToon で描かれます（パスは 1 回）。lilToon はこのパッケージの必須の依存ではなく、焼き込みを使うときだけ必要です。

## 注意・制約

- 接触追従の変形・体に覆いかぶさる変形を使う巣は、**Batching Static を OFF**、マテリアルの **GPU Instancing を OFF** にしてください。詳しくは [Udon ギミックのページ](UdonGimmicks.md#注意制約) を参照。
- 糸の太さは UV 基準なので、メッシュを引き伸ばした方向には太く見えます。
- 数ピクセルしかない遠くの細い糸では、にじみを防ぐために輪郭線とハイライトを自動で弱めます。
- lilToon は任意の依存です。巣の焼き込みを使うときだけ、lilToon（2.3.x で確認）をプロジェクトに入れてください。lilToon が無くても、シェーダーとインスペクタは今までどおり動きます（焼き込みのボタンが押せなくなり、理由が表示されます）。

## 確認チェックリスト

1. 縦糸・横糸の本数、半径、ハブの位置を変えると形が変わり、横糸が途中で切れないこと。
2. 継承元の蜘蛛糸の「粘液感」を下げると、巣も乾いた細い糸に近づくこと。
3. 縦糸の粘液感を 0 にすると、縦糸がまっすぐな一定幅の糸になり、横糸の上に粘液が残ること。
4. 扇形: 開き角度・向きを変えると扇の範囲が変わり、横糸がメッシュの端で止まること。
5. 揺れアニメ: ON で横糸だけが揺れ、縦糸・ハブは動かないこと。
6. lilToon に焼き込む（lilToon を入れたプロジェクト）: 確認画面で同意して焼くと、模様がほぼ同じ見た目のまま lilToon のマテリアルに差し替わり、控えの「元に戻す…」で元のマテリアルと影の設定に戻ること。
